1. 対象と適用期間

標準時間と短時間は、同じ期間にそれぞれ登録できます。同じ区分では期間を重ねられません。ルール名を変えるだけでは区分は変わりません。

2. 延長料金がかからない通常保育時間

園で定めた通常保育の開始・終了時刻を入力します。朝延長は開始時刻より前、夕延長は終了時刻より後を計算します。

{{ number_field('morning_grace_minutes', '朝の猶予時間（分）', v.morning_grace_minutes, 0, 120) }} {{ number_field('morning_rounding_minutes', '朝の課金単位（分ごと）', v.morning_rounding_minutes, 1, 120) }} {{ number_field('morning_unit_price', '朝の1単位の料金（円）', v.morning_unit_price) }}
{{ number_field('grace_minutes', '夕の猶予時間（分）', v.evening_grace_minutes if v.evening_grace_minutes is defined and v.evening_grace_minutes is not none else v.grace_minutes, 0, 120) }} {{ number_field('rounding_minutes', '夕の課金単位（分ごと）', v.evening_rounding_minutes if v.evening_rounding_minutes is defined and v.evening_rounding_minutes is not none else v.rounding_minutes, 1, 120) }} {{ number_field('unit_price', '夕の1単位の料金（円）', v.evening_unit_price if v.evening_unit_price is defined and v.evening_unit_price is not none else v.unit_price) }}

例：課金単位15分・料金100円なら15分ごとに100円（端数切り上げ）。課金単位1分なら1分ごとの料金です。従来計算は夕延長のみです。
