# 園児別・月間の登降園修正（2026-10-04）

## 依頼と実装範囲

月末に登降園の未打刻を補記し、園児一人の指定月をまとめて確認する機能。
試験運転中の多数の抜けに対応するため、管理者が園児ごとの共通時刻を候補へ入れ、違う日だけ直して保存する。
ユーザーが架空データのモック作成後に本番での実装・確認を依頼し、共通時刻方式を選択した。

入口は「登降園管理 → 園児別・月間修正」。月・クラス・園児を指定し、記録のない日も含めて全日を表示する。
編集権限のある職員は日別修正、管理者は一括補完を利用できる。閲覧権限では読み取りのみ。

## 保存動作

- 日別修正：時刻と理由を入力して保存。保存済み時刻の削除は既存の取消画面で行う。
- 一括補完：出席確認または片方の打刻がある日を候補として選択。共通時刻を空欄へ適用し、日別に調整する。
- 出欠未確認の日は任意で表示し、実際の出席を確認して明示的に選択する。欠席、未来、在籍期間外、料金保護対象日は一括補完できない。
- 保存前に対象日数と変更前後を確認する。画面を閉じるだけでは保存しない。
- 一括では既存の打刻を変更しない。同じ時分の既存記録は秒と記録日も保持する。
- 全日を検証後、一つのトランザクションで保存。エラー時は全件を戻し、入力を画面に残す。
- 表示後の打刻・出欠・保護者連絡・料金の変更を検出して競合を止める。
- 未確定の延長料金を再計算する。確定・調整・対象外・請求転送済みの料金は保護する。
- お迎え予定、実際のお迎えの人、補食、出欠そのものは変更しない。
- 既存の修正履歴テーブルへ、修正者・理由・前後時刻・一括処理IDを残す。DB構造は変更しない。
