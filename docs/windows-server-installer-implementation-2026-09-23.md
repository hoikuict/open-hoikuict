## 実装

このPCへの導入、園内LAN、園外利用の順で進める。既存の管理者・保存場所・ポート・導入記録の入力を保持。DNS/SMTP/保存先の確認後にUACを求め、WinSW・Caddy・cloudflaredを設定する。

試用DB・添付・認証鍵をコピーし、正常な起動・HTTPS・バックアップを確認してから利用可能にする。開始前はHTTPとWebSocketの業務アクセスを止める。開始後の記録を失う旧DBへの自動巻戻しは行わない。

サービスは専用の仮想アカウントで動作。コードはProgram Files、データはProgramDataに配置する。秘密情報はDPAPIとACLで保護し、下書き・確認画面・操作記録から除く。構成依頼はハッシュ・有効期限・保存先を検査する。

失敗復旧・中断記録・再起動後の確認、バックアップ保存期間、公開停止と認証メールの保留、再公開時の未送信リンク更新を含む。パスワードのハッシュと既存鍵を引き継ぐ。
