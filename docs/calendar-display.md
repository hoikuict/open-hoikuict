# カレンダーの表示とカレンダー作成

カレンダーは画面の横幅に合わせて広がります。上部の「カレンダー」で左側の一覧・作成・管理パネルを開閉でき、閉じると予定の表示部分が広がります。

## 表示の切り替え

- 月表示と週表示の「日曜日を表示」で、月〜土の6日と月〜日の7日を切り替えます。月表示では列幅も自動調整します。
- 日曜日を非表示にしても予定自体は変更されません。日表示や予定検索では日曜日の予定も確認できます。
- 小さい画面の月表示では予定件数を表示し、件数または日付を押すと当日の予定一覧を開きます。週表示は小さい画面では縦に並びます。
- 日曜日の表示、左パネルの開閉、作成フォームの開閉は、同じブラウザーで職員ごとに保存します。月・週・日の移動、予定保存、カレンダー作成や表示対象の切り替え後も保持します。他の端末・ブラウザーには同期しません。
- 保存された設定がない場合は、日曜日は非表示、左パネルと作成フォームは開いた状態です。ブラウザーの保存領域を利用できない場合も、その画面での切り替えは可能です。

## カレンダーを作成する

1. 上部の「カレンダー」で左パネルを開きます。
2. 「カレンダーを作成」を開き、名前、個人／施設共用、説明（任意）、色を設定します。
3. 「作成する」を押します。作成したカレンダーは一覧と予定作成画面の選択肢に追加されます。

カレンダーの作成は従来どおり管理者のみ可能です。施設共用カレンダーの職員への共有、管理・アーカイブ・復元、予定の権限や通知は既存の機能を使用します。

この表示変更に伴うデータベースの変更や移行作業はありません。
