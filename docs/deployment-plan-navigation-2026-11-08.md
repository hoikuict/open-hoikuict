# 指導計画の入口を光の原保育園の実機に反映

2026年11月8日 07:17 JST、光の原保育園の職員用アプリを切り替えた。職員ログイン後に「指導計画」から開ける。[実機の指導計画](https://hikarinomori.hoikuict.net/plans/)／[決定記録 SD-035](spec-decisions.md#sd-035)

## 職員が確認できる操作

- 新しく書くときは「自園の帳票」の年案・月案・週案・日案を選ぶ。年案は年度とクラス、月案・週案・日案はカレンダーから対象の期間を開く。
- 以前に書いた帳票は「旧式の帳票」から開く。編集できる職員は、旧式の年案・月案を手入力または文例から作れる。
- 「最近の帳票」と帳票一覧には様式名を表示する。月案・週案カレンダーでは、自園の帳票を開く操作と、その期間に保存された旧式を開く操作を分けた。
