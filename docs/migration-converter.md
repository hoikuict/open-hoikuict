# データ移行コンバーター

他のアプリから出力した名簿や、園で使っているExcelの列を対応付けて、open-hoikuictの取込用CSVへ変換します。元の表を作り直す作業を減らし、同じ形式の次の名簿にも変換設定を使えます。

2026年9月15日時点の初版です。列の対応付けによる汎用変換を実装しています。各社アプリの専用設定は、実際の出力見本による検証後に追加します。

## 開き方

- アプリ版：園児台帳管理権限のある職員で「データ入出力」→「データ移行コンバーターを開く」。この機能を含むアプリの更新が必要です。
- 単体版：配布された `hoikuict-data-converter.html` をPCに保存してChromeまたはEdgeで開きます。アプリの更新前でもCSVを作れます。インターネット接続は不要です。

原本を残して作業します。ファイルの読み込みと変換は端末内で行います。アプリ版も「アプリで事前検証」を押すまでは入力データをサーバーへ送りません。単体版は送信機能を持ちません。

## 1. 元データを読み込む

CSV、TSV、Excel（`.xlsx`）を選択します。Excelは対象シートを選び、表より上にタイトルがある場合は「見出しの開始行」を合わせます。見出しが複数段なら1～3行を指定できます。

CSVの文字コードはUTF-8、Shift-JIS、UTF-16に対応します。文字化けする場合は「読込設定」で文字コードを選び直してください。区切り文字はカンマ、タブ、セミコロンです。

### 名簿の並び方に合わせる

| 元の表 | 選ぶ方式・設定 | 出力 |
| --- | --- | --- |
| 園児1人につき1行。保護者情報も同じ行 | 「家庭・園児をまとめて変換」、1行の園児数を1人 | 家庭CSVと園児CSV |
| 家庭1つにつき1行。きょうだいが横に並ぶ | 「家庭・園児をまとめて変換」、1行の園児数を2～4人 | 家庭CSVと園児CSV |
| 保護者1人につき1行 | 「保護者1人1行の表 → 家庭」、家族番号と保護者区分を指定 | 家庭CSV |
| すでに家庭や園児だけの一覧になっている | 対応する単独のデータ種別 | その種別のCSV |

「家庭と園児」で複数行のきょうだいを同じ家庭にまとめるには、元の家族番号の列を選択します。指定しなければ1行を1家庭として扱います。姓や住所が同じという理由ではまとめません。

「保護者1人1行」では家族番号の列と、保護者①・②を区別する列が必須です。たとえば区分が「父」「母」なら、①にする値を「父」、②にする値を「母」と指定します。区分や並び順は推測しません。保護者①の欄で対応付けた氏名・連絡先を、指定された①または②へ入れます。

単独のデータ種別は、家庭、園児、クラス、職員ユーザー、保護者アカウント、保護者・園児紐付けです。職員ユーザーのアプリ内変換と取込は管理者のみ利用できます。

## 2. 列を対応付ける

アプリの項目ごとに、元の列と変換方法を選びます。分かる列名は候補が入りますが、同名列が複数ある場合などは空欄になります。元の値の例を見ながら確認してください。

| 変換 | 例・注意点 |
| --- | --- |
| 姓名の分割 | `山田 太郎` → 姓 `山田`、名 `太郎`。空白で2つに分かれる場合のみ。`山田太郎` は手入力が必要 |
| カナ | `やまだ`、半角カナ → 全角カタカナ |
| 日付 | `令和4年4月1日`、`2022/4/1` → `2022-04-01` |
| Excelの日付番号 | CSVへ数値で出力された日付は、この変換方法を明示的に選択 |
| 性別・在園状態 | 男児・女児、在園・卒園などをアプリの値に統一。数字の独自コードは自動判定しない |
| 値の置き換え | 1行ずつ `A=ひまわり組` のように指定。元の値との完全一致で変更 |
| 空欄の補完 | 元の値が空欄のときだけ、指定した入園日などを使う |

電話番号は文字列を保ちます。Excelの表示形式が0埋めを明示している場合はその桁数を使用します。数値として保存され、先頭の0がすでに失われている場合は警告します。原本を確認して直してください。

移行元の園児番号などをアプリの `ID` に入れないでください。初期状態ではID列を使えません。既存のopen-hoikuictへ更新する場合に限り、取込先から出力したIDを確認して「ID欄には、open-hoikuictから書き出したIDを使う」を有効にします。家族番号は行をまとめるために使い、アプリの内部IDへコピーしません。

### 同じ形式を次回も使う

「変換設定を保存」でJSONを保存できます。次回は元ファイルを読み込んでから「変換設定を開く」を押します。列の順序が変わっても列名で探します。列がない場合や同名列がある場合は再指定します。

保存内容は列の対応、変換方法、値の置換ルール、家庭・保護者の分類設定です。元の行データ、空欄の補完値、変換結果への手修正は含みません。**置換ルールに書いた文字は保存される**ため、共有する設定には個人名や連絡先を書かないでください。シート・見出し開始行・文字コードは、その都度確認します。

## 3. 変換結果を確認する

「変換結果を確認する」を押し、件数と確認事項を見ます。表は横にスクロールでき、セルを直接直せます。取り込まない行は「出力」のチェックを外します。

- 同じ家庭の行どうしで電話番号などが違う場合は、どの値を残すか確認して入力します。
- 家庭名が空欄なら姓＋「家」で補います。同姓の別家庭を区別する名前へ直してください。
- 家庭名を直すと、その家庭に対応する園児の家庭名にも反映されます。
- 家庭を出力対象から外した場合、その家庭の園児は取り込めません。園児も対象から外すなど、対応を確認します。
- 分類できない保護者区分、空の家族番号は、元データまたは分類設定を直します。
- 計算結果が保存されていないExcelの数式セルは、元のExcelで再計算して保存するか、結果を直接入力します。
- 変換しない元の列を確認します。警告がある場合は確認済みのチェックを入れるまでCSVを保存できません。

**元データ・列の対応・変換設定を変更すると、結果の手修正は消えます。** 必要なCSVを先に保存してください。ブラウザーを閉じた場合も作業内容は消えます。「この端末の作業内容を消す」で画面内のデータを消せます。保存済みのファイルは残ります。

「変換レポート」には、出力行に対応する元の行番号、省略した列、確認事項を記録します。元の表全体は含みませんが、ファイル名や確認事項にも個人情報が含まれる可能性があるため、元データと同じ管理場所に保存してください。

## 4. アプリへ取り込む

1. 取り込み前のバックアップを確認します。必要なクラスが未登録ならクラスを先に登録します。
2. **家庭 → 園児** の順に処理します。単体版では「家庭CSVを保存」を押し、アプリの「データ入出力」で家庭を選んで「事前検証」します。アプリ版は「家庭をアプリで事前検証」から別タブで開けます。
3. 事前検証の新規・更新件数と変更内容を確認し、「インポート実行」で確定します。
4. 家庭の確定後、園児CSVも同じ手順で事前検証・確定します。
5. 園児詳細、家族プロフィール、エクスポートで結果を確認します。

変換だけでは登録されません。アプリ側の照合・権限・競合チェックを通して確定します。CSVはUTF-8 BOM付きです。Excelで開き直して保存すると電話番号などが数値へ変わることがあるため、変換したCSVをそのまま取り込んでください。

家庭と園児の確定は別々です。園児側が失敗しても、確定済みの家庭は残ります。同名家庭が取込先に複数ある場合は、家庭をエクスポートして取込先の家庭IDを確認し、園児の単独変換で指定して再検証します。

家庭CSVは、保護者アカウントや閲覧権限を自動作成しません。ログインを開始する場合は[家庭・園児CSVの取り込み](family-guardian-csv-guide.md)の案内に沿って、対象保護者のアカウントと閲覧できる園児を確認します。「保護者アカウント」「保護者・園児紐付け」の単独取込は、それぞれの登録・紐付けを行う明示的な操作です。

## 対応範囲と今後の拡張

- 最大20MB、5,000データ行、300列。Excelは最大100シートから1つを選び、展開後80MBまで。
- Excelの結合セルは見出しで扱います。データ部分の結合セルを推測して埋めません。
- 対応する保護者プロフィールは①・②、1行に横並びの園児は4人まで。
- `.xls`、パスワード付きExcel、PDF・画像の読み取り、写真・添付ファイル、履歴・出欠・健康記録、ログイン用パスワードの移行は対象外です。
- 別ファイルの任意の結合、旧IDから新IDへの永続的な対応表、複数CSVの一括確定は未実装です。[本番データ移行仕様](beta-production-data-migration-spec.md)の専用移行処理を置き換えるものではありません。
- 移行先にない独自項目は、省略列として示します。移行済みとは扱わず、原本を保管してください。

移行元ごとの設定を追加する際は、匿名化したCSV・Excelの見本で、列、コード、家庭・園児・保護者の関係と未対応項目を確認します。まず汎用設定を作り、同じ形式で繰り返し使える設定として蓄積します。

## 開発者向け

`assets/migration/` が読込・変換・画面の共通ソースです。`tools/build-migration-converter.py <出力先HTML>` で、現在のアプリの列定義を含む単体HTMLを生成します。生成時は開発用環境を使用してください。データベースへの接続は不要です。

検証は `test_migration_converter.py`（権限・配信）、`tools/test-migration-converter-core.cjs`（変換・分類・設定）、`tools/test-migration-converter-browser.cjs`（実ブラウザーで読込・CSV保存・既存の事前検証と確定）で行います。ブラウザーテストは合成データと独立したSQLiteメモリーDBを使います。
