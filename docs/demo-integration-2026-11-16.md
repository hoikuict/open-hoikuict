# 11月16日までの変更を公開デモへ適合する

利用者の実機反映・コミットとプッシュ・デモへ反映可能な変更の依頼に基づく。[SD-059](spec-decisions.md#sd-059)。実機の健康管理一覧は `0cadb56` で反映済み。mainの未コミット作業・公開済み更新・本番履歴を統合した `5ba7369` を、デモブランチの `1301253` へマージした。

## 保持と適合

健康一覧の操作欄、計画の入口・検索・保存時の案内・レビュー、保護者医療情報、園児別緊急連絡順、保護者の連絡項目設定、登録・児童票・請求の修正とマニュアルを取り込む。利用者ごとのSQLite、架空職員・保護者の本人選択、期限・入力上限、Push分離、バックアップ・復元等の管理操作の制限を保持する。

デモDBは同梱した架空データのコピーに新しいテーブルを作成し、請求の取消に必要な `zengin_exports.canceled_by` / `canceled_at` を追加する。同梱DBの上書きや、本番DB・本番文例・秘密設定の移送は行わない。既存のデモ専用月案例の読み取り専用マウントを保持する。画像に以前の試用セッションを含めないよう、Dockerの対象から `runtime/` を除外する。

## ローカル検証

関連90テストの初回結果は89成功・1失敗。デモ用コピーに取消2列が不足していたため移行を追加した。修正後の既存デモ互換17件が成功。新規の1件で連絡項目設定を画面と同じリクエストで保存し、別利用者には設定・監査記録が現れないこと、健康一覧の操作リンク、管理操作の404を確認した。共有fixtureの保持と重複importを整理し、RuffとMkDocs strictは成功。

全体CI、候補イメージの隔離HTTP確認、公開デモの更新結果は完了後に追記する。デモの再起動は訪問者の一時入力を初期化する。TrueNAS上の本番コンテナーとデモの公開接続・環境設定を変更しない。
