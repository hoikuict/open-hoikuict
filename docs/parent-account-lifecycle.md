# 保護者の利用停止・再開

保護者アカウントの停止・再開は、管理者が**「認証管理」→「利用停止・再開」**で行います。2026年9月23日のWindows配布版に含まれる操作です。

## 何を変更したいかで入口を選ぶ

| 変更したいこと | 操作する場所 |
| --- | --- |
| アカウント全体の利用を止める・再開する | 保護者アカウントの「認証管理」 |
| 閲覧できる園児を変更する | 保護者アカウント編集の「閲覧を許可する園児」 |
| 保護者を所属家族・家族プロフィールへ対応付ける | アカウント編集・家族プロフィール |
| 園児の在園・卒園・退園を管理する | 園児台帳 |

「所属家族」や「家族プロフィールの保護者」の紐づけを外しても、アカウントの利用停止や園児の閲覧許可の解除にはなりません。目的に合う欄を操作してください。

## 一時的に停止する

1. 保護者アカウント一覧で対象者を確認し、「認証管理」を開きます。
2. 「利用停止・再開」に停止理由を入力します。
3. 「利用停止の内容を確認」を押します。
4. 対象・現在の状態・理由を確認し、「利用を停止する」を押します。

確認画面までは状態は変わりません。対象や理由を直す場合は「修正に戻る」を使います。

停止すると、ログイン中の端末、通知登録、未完了の招待・再設定コードが失効します。現在のパスワードと園児との紐づけは保持されます。

## 現在のパスワードで再開する

1. 対象者の「認証管理」を開きます。
2. 「利用停止・再開」に再開理由を入力します。
3. 「利用再開の内容を確認」を押します。
4. 対象と理由を確認し、「利用を再開する」を押します。
5. 保護者に、現在のパスワードで再ログインしてもらいます。

通常の再開では、パスワードを変更せず、メールも送信しません。停止前のログイン状態・通知登録は復活しないため、必要な端末で再ログインし、通知の利用設定を確認します。

## パスワード設定が必要な場合

「パスワード再設定を伴う利用再開」を開き、本人確認方法と再開理由を入力します。確認画面で「再開案内を送信する」を押すと、登録メールへ案内します。**本人が新しいパスワードを設定するまでログインできません。**

再開手続き待ちの間に案内を再送すると、以前のコードは無効になります。取り消す場合は、取消理由を入力して「再開手続き取消」の内容を確認し、「再開手続きを取り消す」を押します。停止中に戻り、案内のコードも無効になります。

初回登録・パスワード設定が未完了、またはメールアドレス削除済みの場合は、画面に表示される手続きを確認してください。通常の再開ボタンで解消できない状態です。

## 卒園後に弟妹が入園するとき

1. 園児台帳・家庭台帳から、弟妹を既存の家庭に登録します。
2. 既存の保護者アカウントを開き、本人と家庭の対応を確認します。
3. 編集の「閲覧を許可する園児」に弟妹を追加し、許可する園児全体を確認して保存します。
4. アカウントが停止中なら「認証管理」から利用を再開します。
5. 本人に再ログインしてもらい、弟妹が表示されることを確認します。

卒園した子の記録を保持したまま、既存アカウントと現在のパスワードを使って再開できます。同じ家庭へ弟妹を追加しただけでは閲覧許可は増えないため、手順3も行ってください。

新しい保護者の利用開始は[アカウントと利用開始](accounts.md)、台帳の準備から確認する場合は[利用開始マニュアル](start-manual.md)を参照してください。
