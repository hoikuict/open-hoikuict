# Windows導入完了時の権限と監視更新の修正

2026-09-23、v2026.9.23.4からの修正。

- LAN適用後、管理者が置き換えた `installation.json` の所有者が変わり、通常起動の導入アプリで読み取れなかった。元の導入者のSIDを保存先の権限へ明示し、サービス側の状態読取権限と制御情報を用意してから導入記録を公開する。
- Windowsの共有ロックで監視記録の置換が一時的に拒否されると、gatewayの監視が終了していた。記録・秘密情報・復元制御の原子的な置換で最大2秒の再試行を行う。継続する権限エラーは成功扱いにせず伝える。
- 再試行中も直前の完全なファイルを保持する。DB・パスワード・接続先・サービス権限の変更はない。

通常権限から、実際のUAC経由で作成した架空の導入記録を読む試験で旧動作の失敗と修正後の成功を確認した。Windowsの削除共有を許可しない読取ハンドルを使った試験でも、旧置換処理の失敗と修正後の成功を確認。永久的な拒否では元ファイルを保持して失敗することを検証する。

既にLAN適用が完了した環境では、再導入や試用DBへの切戻しを行わず、導入記録の読み取り権限を修復して動作確認へ進む。修復後も、証明書の登録・別端末からの接続・OS再起動後の確認は実際に行う。
