# ホームの差し戻し表示

職員ホーム（`/`、`/staff/portal`）の上部に、本人宛ての未確認の差し戻しを表示します。

- 文書の確認依頼で管理者が「差し戻す」を実行した依頼。
- 日案・週案・月案などの計画文書、および児童票の差し戻し通知。

ヘッダーに件数を表示し、件数を押すと「差し戻しがあります」欄に移動します。欄には文書名、差し戻した人、日時、理由、新しい順の一覧を表示します。「文書を確認」から対象文書を開けます。差し戻しの表示は、ホームを開いたとき・更新したときに反映されます。

対象はログイン中の本人に届いたものに限ります。管理者のホームにも本人宛てだけを表示し、他の職員の差し戻しは表示しません。承認待ちは従来の管理者向け一覧に残ります。

「確認済みにして消す」はホームの表示を整理する操作です。文書を開くだけでは消えません。文書の内容、差し戻し状態、理由、判断者と判断日時は保持します。計画文書は既存の通知確認処理を利用し、確認結果の履歴は文書詳細で確認できます。

文書の確認依頼の修正は、従来どおり新しい依頼として提出してください。計画文書は文書詳細の編集・再提出操作を利用してください。

## 既存環境への反映

文書の確認依頼には、本人による確認日時を保存するNULL許容の `document_review_requests.return_acknowledged_at` を追加します。SQLiteではアプリ起動時に追加し、既存の本文・添付・確認結果を保持します。すでに差し戻された依頼も、確認済みにするまではホームに表示します。SQLite以外では、既存の外部スキーマ管理手順で同じ列を追加する必要があります。

計画文書・児童票には既存の本人宛て通知を使用し、解決済みの通知は表示しません。
