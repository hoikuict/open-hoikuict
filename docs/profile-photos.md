# 園児・保護者の写真と園児の性別

園児の登録・編集画面で、園児の写真と性別、保護者1・2の写真を登録できます。写真と性別は任意です。保護者の性別は登録しません。

## 写真の登録・更新

JPEG・PNG・WebP形式で、1枚10MB・2500万画素以内の写真を選び、プレビューを確認して保存します。差し替える場合は新しい写真を選択し、外す場合は「現在の写真を削除する」にチェックして保存します。

園児の写真は園児一覧の姓の横と詳細画面に表示します。保護者の写真は家族編集画面でも更新でき、同じ家族の兄弟姉妹で共有します。

園児の性別は「未設定・男・女」から選択します。通常の園児一覧には表示しません。CSV/Excelの性別列でも読み書きでき、列の省略・空欄では既存の値を保持します。未設定へ戻す場合は「未設定」を指定します。保育要録などの帳票への転記は今回の追加に含みません。

## 保護者からの申請

保護者は「子ども情報変更申請」から写真・性別の変更を申請できます。園の承認後に台帳へ反映します。職員は申請詳細で変更前後の写真を確認できます。

写真の閲覧にはログインが必要です。保護者が閲覧できるのは、明示的に閲覧を許可された園児とその家族の現在の写真、および自分の承認待ち申請の写真です。

## 保存と履歴

写真は長辺1024ピクセル以内のJPEGへ変換し、位置情報などのメタデータを除去してデータベースへ保存します。元ファイルは保存しません。現在の写真を削除・差し替えしても、過去の申請や職員向け変更履歴の写真は残ります。

写真はDBバックアップに含まれます。CSV/Excelには写真を含めず、取り込みによって既存の写真を消すこともありません。

既存DBの更新では園児の性別を「未設定」、写真を未登録として追加します。登録済みの園児・家族情報は保持します。
