# アカウントと利用開始

職員と保護者は別のアカウント・ログイン入口を使います。家族プロフィールに保護者を登録することと、ログインできるアカウントを有効化することは別の操作です。

## 職員の利用開始

| 操作 | 担当者 | 入口 |
| --- | --- | --- |
| 空DBの初期管理者を作る | サーバー運用担当者 | `python -m scripts.auth_user bootstrap-admin` |
| 初期パスワードを設定する | コードを受け取った職員本人 | `/staff/activate` |
| 職員を追加・編集する | 管理者 | `/staff/users` |
| 初期設定・再設定コードを発行する | 管理者 | 職員管理の「認証管理」 |
| ロール・業務別権限を設定する | 管理者 | `/staff/permissions` |
| 担当クラスを設定する | 管理者 | 職員管理の担当クラス画面 |

CLIはパスワードを受け取りません。初期管理者の作成時に表示する有効化コードは6文字・30分有効で、本人がログインIDを確認し、8文字以上のパスワードを設定します。既存職員がいるDBでは `bootstrap-admin` は停止するため、対象を確認して `activate-staff` を使います。ローカルβでCLIへ正しい環境を渡す方法は[環境設定](environment-profiles.md#bootstrap)を参照してください。

基本ロールは `admin`、`can_edit`、`view_only` です。園児台帳管理や請求口座管理などの追加権限と担当クラスを組み合わせます。園長・主任などの職名だけでシステム権限が決まるわけではありません。

## 保護者の登録方法を選ぶ

| 園の状況 | 登録方法 | 手順 |
| --- | --- | --- |
| 共通の案内を配布して申し込みを受けたい | 共通QRからの初回申請 | [共通QR登録](parent-public-registration.md) |
| 子どもの名前とメールだけ確認できている | 「初回入力を依頼」で招待 | [招待・同期ガイド](guardian-account-sync.md) |
| 園児と家族プロフィールが登録済み | 園児詳細の対象保護者からアカウント登録・招待 | [招待・同期ガイド](guardian-account-sync.md) |
| 台帳の本人情報で照合したい | 登録メールへの招待と本人情報照合 | [保護者認証設計](parent-local-authentication-spec.md) |
| 紙・Excelから初めて台帳を作りたい | 初期台帳Excelを先に取り込み、保護者を招待 | [初期台帳ガイド](initial-ledger-guide.md) |
| 既存の家庭・園児CSVを取り込みたい | CSVの形式と取込対象を確認し、保護者を招待 | [CSVガイド](family-guardian-csv-guide.md) |

共通QRは管理者が受付を開始するまで申請を受け付けません。メール確認と初回入力の後、園が本人・園児との関係・反映先を確認して承認し、本人がパスワードを設定してからログインします。

招待・パスワード設定メールのリンクは、案内メールの登録コードを入力する方法でも進めます。再送後は最新のメールを使います。共通QRと、キオスク端末を有効化するトークンは別のものです。

## 閲覧できる園児を指定する

保護者が閲覧・操作できる園児は、明示的に紐付けた `ParentChildLink` が基準です。同じ家族へ所属させたり、家族の住所を同期したりするだけでは、きょうだいの閲覧権限を増やしません。

保護者アカウント編集では家族で候補を絞り、「この家族の園児をまとめて選択」を明示的に操作できます。保存前に対象園児を確認します。家族プロフィールの保護者とアカウントの同期も、指定した保護者について行います。

## パスワードを忘れた場合

| 利用者 | 現在の復旧方法 |
| --- | --- |
| 一般職員 | 管理者が本人確認後、職員の認証管理から再設定コードを発行。本人が `/staff/reset-password` で設定 |
| 管理者 | `/staff/forgot-password` から登録メールによる復旧。SMTPと施設URLの設定が必要 |
| 保護者 | 園が本人確認後、保護者の認証管理から再設定コードを発行・必要に応じてメール送信。本人が `/parent-portal/reset` で設定 |

保護者向けに現在発行する初期設定・再設定コードは24時間有効です。既存コードの期限は発行時の案内に従います。保護者はログイン中なら `/parent-portal/account/password` でパスワードを変更できます。

職員本人による通常のパスワード変更画面、MFA・回復コードは未実装です。管理者のメール復旧を一般職員・保護者共通の自己復旧機能として案内しないでください。

## 停止・異動と連絡先変更

保護者アカウントの停止・再開は「認証管理」の「利用停止・再開」で行います。通常の再開は現在のパスワードを維持し、本人に再ログインしてもらいます。所属家族・家族プロフィールの紐づけを外す操作では利用停止になりません。[利用停止・再開の手順](parent-account-lifecycle.md)で、卒園後に弟妹が入園する場合も説明しています。

退職・退園などの際は、アカウントの有効状態、認証状態、担当クラス・園児リンクを確認します。メールアドレスの変更は、進行中の招待・未送信メールに影響しますが、連絡先の変更だけでログインIDやパスワードを変更しません。

詳しい保存・失効の条件は[ローカル認証設計](local-authentication-spec.md)、[保護者認証設計](parent-local-authentication-spec.md)、[プロフィール同期](guardian-account-sync.md)を参照してください。
