# クラス用スマホの連絡キオスク

2026-11-23更新。クラス共用のAndroidスマホで、当日の変更・連絡・出欠を確認する。仕様の合意・変更・検証は [SD-065](spec-decisions.md#sd-065) を参照する。

## クラスの画面

「今日の変更・要確認」の下に連絡タイムラインを表示する。未確認が0件でも変更履歴を開け、今日の確認済みを含む履歴を見られる。合同保育向けに全クラスの履歴も閲覧できる。他クラスの変更を確認済みにする操作はできない。

出欠は「出席／私用休み／病欠／不明」をクラス単位で入力し、確認画面を経て送信した時点で記録する。選択だけでは保存しない。打刻や時刻訂正は通常画面で行い、入力者は登録先のクラス名で記録する。

トップのタイムラインは親投稿の日時を基準に直近3時間・新しい順・最大5件を表示する。全体を開く導線は0件でも表示する。返信によって古い親投稿を再掲せず、カード右上の数字を押すと返信を開く。数字が0でも最初の返信を書ける。

## 管理者の設定

「設定 → クラス用スマホ」で、クラスマスターの表示順に全クラスを表示する。端末登録済みのクラス数、利用できる端末数、通知が未設定の端末数を確認できる。端末を用意できたクラスから順に登録する。

クラス詳細には、端末名・登録先クラス・通知設定・登録中／解除済みを表示する。端末登録は管理者が解除するまで有効で、端末の有効期限欄は設けない。過去の30日制限は撤廃した。

### 登録

1. クラスと端末名を入力し、「登録QRを発行」を押す。入力だけではコードを作らない。
2. 共用スマホでQRを読み取り、端末登録を確定する。QR発行だけでは登録完了にならない。
3. 管理画面は実際の登録結果を自動取得し、登録完了と通知設定の案内を表示する。

登録用QRは発行から10分間・一度だけ使用できる。取消は元のクラス詳細へ戻り、発行に失敗した場合は入力内容を保持する。サーバーにはコードのハッシュだけを保存し、発行したページを閉じると元のQRは再表示できない。必要な場合は新しく発行する。

### 解除

「端末登録を解除」を押すと対象クラス・端末名の確認画面を開く。「戻る」では変更せず、「解除する」で確定する。解除後は端末の閲覧・入力を拒否し、通知購読と未送信キューを無効にする。過去の投稿・出欠・監査記録は残す。

再登録は新しいQRで行い、解除済みの古い登録は復活させない。通信途絶で処理結果が不明な場合は未処理と断定せず、状態を再確認する。既に送信した通知の取り戻しは行わない。

## 通知と接続

通知はスマホの「端末」画面で有効にし、Androidの通知許可とテスト通知を確認する。管理一覧の「設定済み」は通知購読があることを示し、通知の到着確認済みを意味しない。

本番は専用の接続入口を通し、一般公開入口からクラス画面・管理画面へアクセスさせない。管理操作には職員の管理者認証とCSRF保護を適用する。接続先・鍵・登録コードはこの文書に記載しない。

端末登録自体に期限は設けない。Cookieは認証成功時に365日分を更新する。ブラウザーのデータ消去や長期未使用によるCookie消失、端末交換では再登録が必要になる。
