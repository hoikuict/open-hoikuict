# 保護者登録マニュアル

**対象：園の登録担当者・管理者と、初めて利用する保護者本人。** 園が案内・確認・承認を行い、保護者本人がパスワードを設定して利用を始める手順です。

**案内 → 保護者が入力・提出 → 園が確認・承認 → 保護者がパスワード設定 → ログインと対象園児を確認**の順に進めます。台帳に保護者名があることや、アカウントを作ったことだけでは登録完了になりません。

## 1. 登録方法を選ぶ {#choose-route}

最初に「保護者アカウント」の一覧で、同じ人のアカウントが既にないか確認します。

| 園の状況 | 使う手順 |
| --- | --- |
| 共通のQRを配り、保護者から申請してもらう | [A. 共通QRから登録](#qr) |
| 在園児の保護者本人の情報、または新入園に必要な初回情報の入力を依頼する | [B. 初回入力を個別に招待](#enrollment) |
| 園児・保護者の台帳が揃い、本人情報の照合で招待する | [C. 台帳から招待](#identity-invite) |
| 既にログインできるアカウントがある | 新規登録せず、必要なら[閲覧園児を追加](#children) |
| アカウントが停止中 | [利用停止・再開の手順](parent-account-lifecycle.md) |
| 初回設定が未完了・パスワードを忘れた | [困ったときの対応](#troubleshooting) |

### 園での準備

- 招待・承認・コード発行は**管理者**が行います。園児・保護者の台帳を編集する担当者には**園児台帳管理の権限**も必要です。
- 園の利用URLが保護者の端末から開け、登録メールを送受信できることを運用担当者が確認します。
- 保護者ごとに、本人が受信できるメールアドレスを確認します。初回のログインIDになります。
- 園児の氏名・生年月日、本人との関係を確認します。同じ家庭でも、利用する保護者ごとにアカウントを用意します。

保護者用のログイン入口は、施設URLの後ろに **`/parent-portal/login`** を付けた画面です。

## A. 共通QRから登録する {#qr}

### A-1. 受付を開始し、QRを配る［園・管理者］

1. メニューの**「保護者アカウント」**を開きます。
2. **「共通QR・申請受付」**を押します。
3. 表示された施設URLを確認し、**「新しい申請の受付を開始する」**を押します。
4. **「案内を印刷」**または**「QR画像を保存」**を使い、保護者へ配ります。

全員に同じQRを使います。受付が「停止中」のままでは、新しい申請を受け付けません。受付を停止しても、提出済み申請の承認や既存アカウントのログインは続けられます。

### A-2. メールを確認して情報を提出する［保護者本人］

1. 園から受け取ったQRを読み取ります。
2. 「保護者ご本人のメールアドレス」を入力し、**「登録案内メールを受け取る」**を押します。
3. 届いたメールの登録リンクを開き、[初回情報入力](#initial-information)を行います。
4. **「入力内容を園に提出する」**を押し、園の確認を待ちます。

この時点では、まだログインできません。

### A-3. 申請を確認・承認する［園・管理者］

1. 「保護者アカウント」の**「確認待ちの初回登録」**から、対象者の**「提出内容を確認する」**を押します。
2. 「共通QRからの初回申請」であること、メールアドレス、保護者本人・園児との関係、提出内容を確認します。
3. **「承認先の園児・保護者」**を選びます。登録済みなら既存の対象者を選び、未登録の場合だけ「新しい園児・家族を登録する」を選びます。
4. 「確認理由」を記入し、確認済みのチェックを入れて**「承認」**を押します。
5. 保護者には、承認後のメールから[パスワード設定](#password)を行ってもらいます。

氏名だけで判断せず、生年月日と本人との関係も確認します。対象や提出内容に誤りがある場合は承認せず、本人に確認してください。却下する場合は理由を記録して「却下」を押します。

## B. 初回入力を個別に招待する {#enrollment}

### B-1. 園児と保護者を指定する［園・管理者］

**既に園児台帳にいる場合**

1. 「保護者アカウント」→**「在園児の保護者を追加・招待」**を開きます。
2. 「在園児」を選び、**「選択」**を押します。
3. 登録済みの保護者なら対象者の**「この保護者を招待」**、まだ家族プロフィールにいない人なら**「新しい保護者を追加」**を押します。
4. 対象園児を確認し、保護者本人のメールアドレスを入力します。
5. **「初回入力の招待を送信」**を押します。

「登録済み・認証管理」と表示される人は、既存のアカウントを使います。園児詳細の家族プロフィールから「この保護者に初回入力を依頼」へ進む方法もあります。

**まだ園児台帳にいない場合**

1. 「在園児の保護者を追加・招待」画面の下部にある**「まだ園児台帳にいない子どもの新規入園受付」**を押します。
2. **子どもの名前・保護者のメールアドレス**を入力します。
3. **「初回入力の招待を送信」**を押します。

### B-2. 情報を入力・提出する［保護者本人］

!!! info "在園児への招待の入力項目について"
    2026-11-01、在園児への「この保護者を招待」「新しい保護者を追加」を[本人情報だけの入力へ修正](parent-existing-guardian-implementation-2026-11-01.md)しました。対象のTrueNAS実機へ反映済みです。[実機配備記録](deployment-parent-guardian-2026-11-01.md)を参照してください。以下は修正版の手順です。

届いた招待メールから[初回情報入力](#initial-information)を行い、**「入力内容を園に提出する」**を押します。メールアドレスは招待先を使うため、再入力しません。

在園児への招待では、表示されたお子さまを確認し、**ご本人の姓・名・姓と名のカナ・続柄・電話番号**を入力します。勤務先・勤務先住所・勤務先電話は任意です。園児の生年月日・入園日・住所・健康情報を入力し直す必要はありません。変更がある場合は園へお知らせください。「入力をやめる」で確認を取り消せば入力を続けられ、終了すれば園へ提出せずに終わります。

### B-3. 確認・承認する［園・管理者］

1. 「保護者アカウント」の「確認待ちの初回登録」から**「提出内容を確認する」**を開きます。
2. 招待したメールアドレス、園児と保護者の対応、提出内容を確認します。
3. 「確認理由」を記入し、確認済みのチェックを入れて**「承認」**を押します。
4. 台帳への反映を確認し、本人には承認後のメールから[パスワード設定](#password)を行ってもらいます。

在園児への招待では、保護者本人の情報と選んだ園児の閲覧権限へ反映し、園児情報・家庭共通情報は保持します。招待後に台帳が変更され、承認が止まった場合は、最新情報を確認してから対応します。承認のために新しい園児を作り直さないでください。

修正前に提出済みの申請は「旧形式の提出内容」と表示します。その場合は園児・家庭共通の項目も含め、提出時の内容を確認して承認します。発行済みでも未提出なら、修正版の画面で本人の情報だけを入力できます。

## 初回情報入力の項目［保護者本人］ {#initial-information}

在園児への個別招待は、上記B-2の本人9項目です。次の表は**共通QRからの申請（A）と、新入園への個別招待（B）**に使用します。

| 入力するもの | 内容 |
| --- | --- |
| お子さま | 姓・名、姓・名のカナ、生年月日、入園日 |
| 自宅の連絡先 | 自宅住所、自宅電話（ある場合） |
| 保護者本人 | 姓・名、姓・名のカナ、続柄、電話番号。勤務先などは該当する場合に入力 |
| もう1人の保護者 | 新規入園等で欄が表示された場合に任意で入力 |
| 健康面で伝えたいこと | アレルギーなど、該当する場合に入力 |

「必須」の欄を確認し、入園日などが分からない場合は園へ確認してください。入力画面は**2時間有効**です。最後に「入力内容を園に提出する」を押します。

既存園児について任意項目を空欄で提出した場合、園に登録済みの値は保持されます。削除したい情報があるときは園へ知らせてください。

**「もう1人の保護者」を入力しても、その人のログインアカウントは作られません。** 園が別途招待します。

## C. 台帳から本人情報の照合で招待する {#identity-invite}

### C-1. 台帳と閲覧対象を確認する［園の登録担当者］

1. 園児詳細の家族プロフィールで対象者の**「この保護者のアカウントを登録」**を開きます。対象者がいない場合は「保護者アカウント」の「新規登録」から登録します。既存アカウントがある場合は「編集」を使います。
2. 表示名、メールアドレス、保護者の**「登録照合用氏名」「照合表記」**を確認します。照合用氏名はカナまたは英字です。
3. **「閲覧を許可する園児」**に、本人が利用する園児を選びます。所属家族や家族プロフィールの対応も確認します。
4. **「登録する」**（編集時は「更新する」）を押します。
5. 園児の編集画面で、その園児の**「保護者登録の照合用氏名」「照合表記」「生年月日」**を確認して保存します。

通常の氏名・フリガナとは別に、登録照合用の項目があります。招待前に「認証管理」で不足項目が表示された場合は、案内に従って補ってください。

### C-2. 招待を送る［園・管理者］

1. 対象保護者の**「認証管理」**を開きます。
2. 氏名・メールアドレスを確認し、「初回登録の案内」の**「招待理由」**を入力します。
3. **「招待を送信・再送」**を押します。
4. 「登録申請の履歴」と「メールの配送状況」を確認します。

### C-3. 本人情報を提出する［保護者本人］

1. 招待メールのリンクを開きます。
2. 「本人情報の確認」で、園に登録した**保護者氏名・園児氏名をカナまたは英字**で入力し、その園児の**生年月日**を入力します。
3. **「園へ確認を依頼する」**を押します。

漢字の氏名では照合しません。きょうだいがいる場合は、園が閲覧対象に設定した園児1人の氏名と生年月日を使います。この入力画面の有効時間は**15分**です。

### C-4. 照合結果を確認・承認する［園・管理者］

1. 「認証管理」の「登録申請の履歴」を開き、確認待ちの申請を確認します。
2. 「保護者氏名」「園児氏名」「生年月日」がすべて**「一致」**していることと、本人・園児との関係を確認します。
3. 「確認理由」を記入し、**「承認」**を押します。
4. 本人には、承認後のメールから[パスワード設定](#password)を行ってもらいます。

不一致の場合は入力内容と台帳を確認します。一致させるためだけに、誤った情報へ台帳を書き換えないでください。

## パスワードを設定し、利用開始する［保護者本人・A/B/C共通］ {#password}

1. 園の承認後に届く**パスワード設定の案内メール**を開きます。
2. メールのリンクを開き、「新しいパスワード」と「確認用パスワード」に同じものを入力します。**8〜128文字**で設定します。
3. **「パスワードを設定する」**を押します。
4. 保護者ログイン画面で、**ログインID（初回登録したメールアドレス）と設定したパスワード**を入力してログインします。
5. 自分のお子さまが表示されることを確認します。表示対象が違う場合は操作を進めず、園へ連絡してください。

メールのリンク・登録コードは**24時間・1回限り**です。リンクが開けないときは、メールに記載された「登録コードまたはメールのリンク」を入力する方法でも進めます。再送後は最新のメールを使います。

## きょうだい・もう1人の保護者を追加する［園］ {#children}

### 既存アカウントで、きょうだいも利用する

1. 園児台帳で、きょうだいが正しい家庭に登録されていることを確認します。
2. 「保護者アカウント」で対象者の**「編集」**を開きます。
3. **「閲覧を許可する園児」**できょうだいを追加し、閲覧対象全体を確認して**「更新する」**を押します。
4. 本人に画面を開き直してもらい、対象園児が表示されることを確認します。

同じ家庭に登録しただけでは、きょうだいの閲覧許可は増えません。「この家族の園児をまとめて選択」を使った場合も、保存前に対象を確認します。

### もう1人の保護者も利用する

その人のアカウントがないことを確認し、[Bの在園児への招待](#enrollment)または[Cの台帳からの招待](#identity-invite)を行います。家族プロフィールへの追加と、ログイン用アカウントの招待は別の操作です。

## 登録完了の確認［園・本人］

- [ ] 本人のメールアドレスと、園児・保護者の対応が正しい。
- [ ] 園が申請内容を確認・承認している。
- [ ] 本人がパスワードを設定し、保護者用の画面からログインできる。
- [ ] 閲覧を許可した園児が表示され、不要な園児が含まれていない。
- [ ] きょうだいや、もう1人の保護者の追加が必要な場合は、それぞれ設定を終えている。

## 困ったときの対応 {#troubleshooting}

| 状況 | 保護者本人・園の対応 |
| --- | --- |
| メールが届かない | 本人は迷惑メールと入力アドレスを確認。園は「認証管理」→「メールの配送状況」で宛先・状態を確認。メールサーバー受付済みでも受信箱への到着は別に確認する |
| メールが古い・期限切れ | 最新のメールか確認し、園へ再案内を依頼。初回入力の招待を再送すると、以前のリンクと未承認の提出内容は取り消されるため、園は申請状態を先に確認する |
| 提出したがログインできない | 園の承認、承認後のメール、本人のパスワード設定のどこまで進んだか確認する |
| QRから申請できない | 園は受付が開始されているか確認。既存アカウントがある場合は新規申請せず、そのアカウントの認証管理を使う |
| 「しばらく待つ」などの表示が出る | 画面の案内に従って間隔を空ける。園のWi-Fiでは複数人の申請が同じ接続元の制限にかかる場合がある |
| 園児が表示されない | 園が「閲覧を許可する園児」を確認。家族との紐づけだけでは閲覧できない |
| アカウントが停止中 | 新規登録せず、管理者が[利用再開](parent-account-lifecycle.md)を行う |
| パスワードを忘れた | 管理者が本人確認後、認証管理で理由を入力し「再設定コードを発行してメール送信」。本人が案内のコード入力画面で再設定する |

### 初回パスワード設定だけが残っている場合

管理者は、既存アカウントの状態と本人を確認し、画面に**「初回設定コードを発行してメール送信」**が表示される場合は、理由を記録して発行できます。本人はメールの案内から6文字のコードを入力し、パスワードを設定します。コードは24時間・1回限りです。

初回入力が未承認の場合は、先に提出内容を確認・承認します。コード発行で承認を省略する手順ではありません。現在の画面ではコード発行と同時にメール送信も受け付けるため、「メールを送らない操作」として案内しないでください。
