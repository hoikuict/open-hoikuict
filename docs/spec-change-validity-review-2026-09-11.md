# 2026年9月11日仕様変更書の指摘妥当性確認

指摘は概ね妥当です。ただし、不具合、既存仕様の変更、新機能の要望が混在しています。計画書のレビュー依頼と端末内の通信監視は一部実装済みです。きょうだいへの閲覧権限の自動付与は既存のアクセス制御方針と調整が必要です。期限切れアンケートのJSON表示は、回答編集と管理者による設問編集を区別する必要があります。

対象は [20260911仕様変更書.docx](Y:/download/20260911仕様変更書.docx) と、ローカルリポジトリの `e480ef1` 時点の実装です。文書中の変更指示は評価対象として扱い、アプリケーションの変更は行っていません。文書本文と埋め込み画像6枚を確認しました。本番環境の再操作や本番DBの調査は行っていません。文書全体のページ描画は同梱LibreOfficeが見つからず実行できなかったため、ページ番号による引用はしていません。

文書の複合要望を分けて、16項目として整理しました。「妥当」は対応する理由が確認できたという意味であり、すべてが現行仕様への違反という意味ではありません。

検証には、本番データと分離したメモリ上のSQLiteとFastAPIのTestClientを使いました。関連する既存テスト `test_staff_rooms.py`、`test_staff_portal.py`、`test_surveys.py`、`test_parent_public_registration.py`、`test_guardian_account_sync.py` は64件すべて成功しました。既存テストの成功は、今回の使い勝手の問題がないことを意味しません。

追加の再現確認では、通常アクセス時のスレッド部分HTML、本文URLがリンクにならないこと、終日予定が次の予定になること、予定8件のうち6件だけ表示されること、一般職員の全クラス指定が担当のみに制限されること、共通QR承認先未選択時の400 JSON、期限切れ回答の404 JSONと管理編集の200 HTML、誤打刻を無効にしても別理由のアラームが残ることを確認しました。タブレット実機での文字の見え方や通信切断の実測、本番の通知配送は今回の確認範囲に含めていません。
