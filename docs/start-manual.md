# 利用開始マニュアル

PCへの導入から、Excelの初期台帳、保護者の利用開始・停止・再開までを順番に進めるためのマニュアルです。2026年9月23日のWindows配布版と、その版に含まれる機能を基準にしています。

[Windows用アプリをダウンロード](https://github.com/hoikuict/open-hoikuict/releases/latest/download/OpenHoikuICT.exe){ .md-button .md-button--primary }
[対応PCと配布内容](download.md){ .md-button }

## 1. 利用する環境を決める

| 目的 | 進め方 |
| --- | --- |
| 新しいWindows PCで操作を試す | このマニュアルの手順2から進み、架空データで試します。 |
| すでに導入済みの園の台帳を準備する | 園が用意したアプリに管理者としてログインし、手順3へ進みます。 |
| Windows PCを園内サーバーにし、その後に園外からも使う | [Windowsの段階別導入手順](windows-server-setup.md)で、園内接続・メール・バックアップ、園外公開の順に進みます。TrueNASは[導入方法](getting-started.md)を参照してください。 |

導入アプリは、最初にこのPCだけのローカル試用を準備します。その後、同じアプリで園内LAN・園外利用へ進めます。実際の園児・保護者の情報は、園で利用を承認した環境で扱います。このマニュアルの氏名や連絡先はすべて架空の例です。

## 2. アプリを導入してログインする

1. [ダウンロードページ](download.md)から **OpenHoikuICT.exe** を保存して開きます。
2. 「このPCに導入する」を選び、GitHubの最新版確認が終わったら、版番号と変更内容を確認します。
3. 「次へ」を押し、管理者の**名前・メールアドレス・パスワード・確認用パスワード**を入力します。
4. 保存場所やログインIDを変える必要がある場合は、詳細欄で設定します。
5. 内容を確認し、**「ダウンロードして準備」**を押します。
6. 完了したら保存場所を控え、導入ホームの**「起動してログイン画面を確認」**からログインします。既定のログインIDは入力したメールアドレスです。

管理者情報を入力しただけでは導入は確定しません。準備を始める前は「戻る」「変更」で修正できます。失敗した場合は画面の案内に従って再試行します。

次回は、完了画面に表示された**保存先の OpenHoikuICT.exe** を開きます。詳細は[かんたん導入](beta-quickstart.md)を参照してください。

## 3. 初期台帳用のExcelを用意する

園児台帳の管理権限がある職員が、**「インポート・エクスポート」→「初期台帳をExcelから登録」**を開き、**「入力用Excelをダウンロード」**を押します。

元の名簿や緊急連絡表は保管し、コピーから取り込み用ファイルを作ります。「入力用」シートの**5行目から、園児1人につき1行**で入力します。

| 確認すること | 入力方法 |
| --- | --- |
| 園児の氏名 | 姓と名、姓カナと名カナを別の列にします。カナはカタカナで入力します。 |
| 生年月日・入園日 | 原本で確認した西暦の日付を入力します。入園日は必須です。 |
| 在園状態 | 「在園」「卒園」「退園」から選びます。 |
| 同じ家庭のきょうだい | 「きょうだいグループ」に同じ文字を入れます。姓だけでは家庭をまとめません。 |
| 保護者 | ①②それぞれの欄に入力します。連絡先がある場合は姓と名も必要です。 |
| 電話番号 | セルを文字列にして先頭の0を保持します。 |

元表に入園日がない場合は、準備中は空欄で残し、**取り込みを確定する前に個別に確認して入力**します。推測の日付で埋める必要はありません。

1行に複数のきょうだいがいる元表、重複、勤務先・部署のまとめ方、読み込まれない項目の保管方法は[初期台帳のExcel準備・登録](initial-ledger-guide.md)で説明しています。

## 4. 読み込んで確認し、台帳に登録する

1. Excelファイルを選び、**「読み込んで確認する」**を押します。この時点では台帳に登録されません。
2. 園児・家庭・クラスの件数とエラーを確認します。
3. 「家庭のまとめ方」で、きょうだいと保護者が正しくまとまっているか確認します。
4. 修正が必要なら画面で直し、**「編集内容を再確認する」**を押します。
5. エラーが解消したら**「登録内容の最終確認へ」**を押します。
6. 確認のチェックを入れ、**「台帳に登録する」**を押します。ここで初めて保存されます。
7. 完了画面から園児台帳と家庭台帳を開き、登録内容を確認します。

やり直すときは「修正に戻る」、確定前にやめるときは「今回の読み込みを取り消す」を使います。画面上の修正は元のExcelには書き戻されません。

これは初回登録用の機能です。登録済み園児の修正や、既存家庭への弟妹の追加は園児台帳・家庭台帳から行います。

## 5. 保護者が利用できるようにする

初期台帳の登録で作られるのは、園児・家庭・保護者の台帳です。**ログイン用アカウントの作成、園児の閲覧許可、招待メール送信は別の操作**です。

1. 家族プロフィールの保護者名・連絡先を確認します。
2. [アカウントと利用開始](accounts.md)から、園児詳細の保護者を招待する方法、共通QRなど、園の運用に合う方法を選びます。
3. 保護者アカウント編集の**「閲覧を許可する園児」**で、本人が利用する園児を確認して保存します。
4. 本人が初回設定を終えたら、正しい園児が表示されることを確認します。

所属家族や家族プロフィールとの紐づけだけでは、閲覧許可の追加・削除や、アカウントの停止は行われません。ローカル試用版ではメールを実際には配送しないため、実メールによる招待の確認はメール設定済みの園の環境で行います。

## 6. 利用を停止・再開する

保護者アカウントの**「認証管理」→「利用停止・再開」**で行います。

- 停止するとき：停止理由を入力し、内容を確認して**「利用を停止する」**を押します。
- 通常の再開：再開理由を入力し、内容を確認して**「利用を再開する」**を押します。現在のパスワードを使って再ログインできます。
- パスワードの再設定が必要なとき：**「パスワード再設定を伴う利用再開」**から案内を送り、本人が設定を終えてから再開します。

停止中もパスワードと園児との紐づけは保持されます。停止前のログイン状態や通知登録は自動では戻りません。

卒園した子の弟妹が入園する場合は、既存家庭に弟妹を登録し、保護者の**「閲覧を許可する園児」へ弟妹を追加**してから利用を再開します。詳細は[保護者の利用停止・再開](parent-account-lifecycle.md)を参照してください。

## 7. 終了・次回起動・データの保管

ローカル試用では、導入アプリの**「導入アプリを終了」**で保育ICTも停止します。ブラウザーのタブを閉じるだけでは停止しません。園内LANへ切り替えた後は、導入画面を閉じてもサーバーは動き続けます。

次回は保存先にある `OpenHoikuICT.exe` を開きます。実行ファイルだけを移動せず、`app`・`runtime` と一緒に保管します。ローカル試用のデータを退避する場合はアプリを終了し、保存先フォルダー全体を管理できる場所へコピーします。

園のサーバーでは[バックアップと復元の手順](backup-restore-spec.md)に従います。導入済み環境の更新は、今回のダウンロードアプリでの上書き再導入とは別の作業です。
