## ユーザーの指定

- Google Driveに保存されている帳票の実物に、画面の帳票様式を合わせる。
- 最初は本文が空白の帳票を表示し、候補を選ぶと対応する欄へ文章が反映される。

- 3歳児クラス以上は集団の様式を使う。

## 指定された文例DBの利用可否

ユーザーが指定した `C:/python/getsuan-rag/getsuan.sqlite` を、2026-09-27に SQLite の `mode=ro` と `PRAGMA query_only=ON` で確認した。既存DBの更新・再取り込み・コピーは行っていない。文例の検索元として利用できる構造である。画面案の架空文例を実DBに接続する変更は、この確認時点では未実施。

- 文例128,008件、正規化本文の重複を除くと60,668件。年齢0〜5歳、月1〜12月、年の値2012〜2026を保持する。年齢未設定の2件は年齢別候補へ自動混入させない。
- `phrase` が文例本文・年齢・月・年・項目・個人別／クラス全体等の区分・領域を持つ。`cell` に元のセル、`source` に元資料の相対パス等があり、出典を紐づけられる。文例から元セル・資料への欠損参照は0件だった。
- 元資料は読み取り成功1,488件（乳児899件、幼児589件）。別に取り込みエラーの資料8件が記録されているため、すべての元資料が取り込めているとは扱わない。
- `phrase_fts` にtrigramの全文検索索引がある。「手洗い」の検索は2,917件。短い語は本文の部分一致を使えることを確認した。
- 1歳児・10月・個人別の重複なし候補数は、生活・健康689件、あそび528件、環境構成・援助474件、評価・反省157件。

画面を接続する際は帳票の行・列と直接編集の操作を維持し、選択セルから年齢・月・区分・項目・領域を指定して検索する。対応は次を基準にする。

| 画面の欄 | DBの検索条件 |
| --- | --- |
| 個人の生活・健康／あそび／評価・反省 | `section=個人別` と同名の `item` |
| 個人の環境構成・援助活動 | `section=個人別`、`item=環境構成・援助` |
| クラス共通のねらい／家庭との連携／評価・反省 | `section=クラス全体` と同名の `item` |
| 幼児の養護・教育の4列 | 区分と領域を指定し、列を `ねらい`／`環境構成`／`予想される子どもの姿`／`援助・配慮` に対応付ける |
| 1枠にまとめた食育 | `section=食育 OR item=食育` を年齢・月で絞り込む。元の項目名も出典情報に保持する |

既存 `getsuan-rag/app.py` の `/api/search` と `/api/forms` が参考になる。DBはローカルの読み取り専用データソースとし、実装時に園のデータソース設定と閲覧権限へ紐づける。画面内の固定候補を検索する操作見本と、全DBを検索するサーバー連携は区別する。

このDBには園児を月をまたいで識別する安定したIDがない。`age_label` は個人別計画の月齢情報で、個人の永続IDではない。そのため文例としての利用は可能だが、「選択した園児の過去3か月の計画と反省」は別の園児ID付き月次記録に接続する必要がある。

## 連携契約との対応

現行 `docs/integration-contract.md` の月案10項目だけでは、個人別4列や幼児の領域×4列を損失なく保持できない。永続キーを表示ラベルに合わせて置換しない。

- `monthly_goal` と `monthly_family_collaboration` はクラス共通欄への対応候補。
- `monthly_environment` / `monthly_support` は幼児の領域ごとの欄と1対1ではない。「環境構成・援助活動」は乳児原本では結合された1項目で、機械的に分割しない。
- `monthly_reflection_viewpoint` は「振り返りの観点」であり、実施後に書く「評価・反省」の実績と同一視しない。
- `children_snapshot` と「予想される子どもの姿」は観察済み・予測の意味が異なる。区別して扱う。
- `monthly_events` を表示する際も、幼児の月日単位の情報は保持する。
- 本実装時は帳票ID・版、年齢クラス、クラスと月、個人の安定参照ID、領域・列を表すフィールドIDを追加設計する。本文と出典をフィールドごとに保持し、名前や行番号を個人の永続IDにしない。
- 画面案は年齢・架空の園児IDでデータを分離した操作確認用。複数クラス・複数月・実園児を扱う保存契約や権限を実装したものではない。
