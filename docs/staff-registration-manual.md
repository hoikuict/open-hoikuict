# 職員登録マニュアル

!!! info "QR付き印刷の追加版について"
    2026-11-01に[QR付き案内の印刷](staff-auth-print-implementation-2026-11-01.md)を実装し、対象のTrueNAS実機へ反映しました。[実機配備記録](deployment-staff-auth-print-2026-11-01.md)を参照してください。以下の印刷手順は更新版の画面向けです。ボタンがない配備版では、コードと設定画面のURLを本人へ個別に渡してください。

**対象：園の管理者と、初めて利用する職員本人。** 管理者がログインできる園で、職員を1人ずつ登録する手順です。最初の管理者の準備は[利用開始マニュアル](start-manual.md)を参照してください。

**管理者が職員を追加 → 権限・担当クラスを確認 → 有効化コードを交付 → 本人がパスワードを設定 → ログインを確認**の順に進めます。職員一覧へ名前を追加しただけでは、ログインの準備は完了しません。

## 1. 登録前に用意するもの

管理者は、対象職員の氏名・メールアドレス、担当業務、必要な担当クラス・担当期間を確認します。本人には、園から案内する施設URLを使ってもらいます。

| 用途 | 開く画面 |
| --- | --- |
| 管理者・職員のログイン | 施設URLの後ろに `/staff/login` |
| 職員を追加する | メニューの「設定」→「職員管理」 |
| 本人の初回設定 | 職員ログイン画面の「初めて利用する方・有効化コードをお持ちの方」 |

既に職員一覧にいる場合は新規追加せず、その人の「認証管理」を開きます。一覧に見当たらないときは「停止済みの職員も表示」も確認してください。

## 2. 職員を追加する［管理者］ {#add-staff}

1. 管理者のアカウントでログインし、「設定」→「職員管理」を開きます。
2. **「職員を追加」**を押します。
3. 次の項目を入力します。

| 画面の項目 | 入力する内容 |
| --- | --- |
| 表示名 | 対象職員の氏名 |
| メールアドレス | 対象職員のメールアドレス。他の職員と重複する場合は登録済みか確認 |
| 権限 | 「管理者」「編集可」「閲覧のみ」から担当業務に合うものを選択 |
| 表示順 | 一覧の表示順。指定がなければ初期値の `100` のまま |
| 有効 | 利用を開始する職員はチェックを入れる |

4. **「職員を追加」**を押して保存します。
5. その職員の「認証管理」が開いたら、氏名・メールアドレスが正しいことを確認します。

この操作では有効化メールは自動送信されません。入力エラーが出た場合は表示された内容を直し、保存後の画面まで確認してください。

## 3. 権限と担当クラスを設定する［管理者］ {#permissions}

### 業務別の権限

1. 「職員管理」の**「権限設定」**を開きます。
2. 対象職員の基本権限と、「園児台帳管理」「請求管理」など必要な業務別権限を確認します。
3. **「この職員の権限を保存」**を押します。

園長・主任などの職名だけで、システム上の権限が決まるわけではありません。職員追加時に選ぶ基本権限と、業務別の権限を両方確認します。

### 担当クラス

1. 「職員管理」で対象者の**「担当クラス」**を開きます。
2. クラス、担当区分、開始日を選びます。終了日が決まっていれば入力し、表示順・主表示も必要に応じて設定します。
3. **「追加する」**を押し、「担当履歴」に正しいクラスと期間が表示されることを確認します。

複数クラスを担当する場合は、クラスごとに追加します。同じクラスに複数の職員を登録する場合は、それぞれの職員の「担当クラス」で設定します。

月案に関する管理者の担当割当条件は、[仕様の決定記録 SD-001](spec-decisions.md#sd-001)で最終合意を確認中です。本書では「管理者は全員、全クラスに担当登録する」といった一律の設定は案内しません。

## 4. 有効化コードを本人へ渡す［管理者］ {#issue-code}

本人が初回設定を行える時間に合わせて発行します。

1. 「職員管理」で対象職員の**「認証管理」**を開きます。
2. 「ログインID」を確認します。初回の候補はメールアドレスです。
3. 「発行理由」に、例として「新規採用職員の初期設定」と入力します。
4. **「有効化コードを発行」**を押します。
5. 対象者・有効期限を確認し、次の3点を本人に個別に渡します。

| 本人へ渡すもの | 内容 |
| --- | --- |
| 初回設定の入口 | 施設URLの後ろに `/staff/activate` |
| 有効化コード | 発行画面に表示された6文字 |
| ログインID・有効期限 | 発行時に確認したIDと、画面に表示された期限 |

コードは**発行から30分・1回限り**です。画面を閉じると同じコードは再表示できません。期限切れ・紛失の場合は「認証管理」から再発行し、本人には最新のコードを使ってもらいます。

コードはパスワードではありません。パスワードは職員本人が設定します。

### QR付きの案内を印刷する（更新版）

1. コード発行後の画面で、本人の氏名・ログインID・有効期限を確認します。
2. **「QR付き案内を印刷」**を押し、A4・縦で印刷します。ブラウザーの印刷設定でヘッダー・フッターをオフにすると、URLやページ番号の余分な印字を避けられます。
3. 印刷した用紙を本人へ個別に渡します。本人はQRを読み取り、用紙の6文字のコードを入力して初回設定へ進みます。

印刷をキャンセルしてもコードと期限は変わりません。30分は**コードの発行時から**数えます。画面を離れた後は同じコードを再表示できないため、必要なら再発行し、古い用紙を破棄します。施設URLの設定エラーが出た場合は、運用担当者に確認してください。

## 5. 初回設定してログインする［職員本人］ {#staff-first-login}

1. 園から受け取った初回設定のURLを開きます。職員ログイン画面から進む場合は**「初めて利用する方・有効化コードをお持ちの方」**を押します。
2. 6文字の有効化コードを入力し、**「コードを確認して次へ」**を押します。
3. 「ログイン情報を設定」画面で、自分の氏名とログインIDを確認します。IDは変更できますが、園の決めたルールがあればそれに合わせ、確定したIDを控えます。
4. 「新しいパスワード」と確認欄に、同じパスワードを入力します。**8〜128文字**で設定し、入力エラーが出た場合は画面の案内に従って変更します。
5. **「ログイン情報を設定」**を押します。
6. 職員ログイン画面で、確定したログインIDとパスワードを入力してログインします。

初回設定後は自動ログインされません。初回設定でIDを変更した場合、連絡先メールアドレスではなく、変更後のIDでログインします。

## 6. 登録完了を確認する［管理者・本人］

- [ ] 職員一覧の認証状態が「設定済み」になっている。
- [ ] 職員情報が「有効」で、基本権限・業務別権限が担当業務に合っている。
- [ ] 必要な担当クラスと担当期間が登録されている。
- [ ] 本人がログインでき、担当業務の画面を利用できる。
- [ ] ログアウト後も、本人のIDとパスワードで再ログインできる。

## 7. うまくいかないとき {#troubleshooting}

| 状況 | 確認・対応 |
| --- | --- |
| メールアドレスが重複して追加できない | 既に職員一覧にいないか確認。停止済みの表示も確認し、既存の職員情報を使う |
| コードを使えない | 職員用の初回設定画面か、30分以内か、最新・未使用のコードか確認。期限切れなら管理者が再発行 |
| ログインできない | 初回設定を最後まで終えたか、確定したIDを使っているか、職員が有効か確認 |
| ログインできるが操作できない | 管理者が「権限設定」と担当クラス・担当期間を確認する |
| 入力を繰り返した後に制限された | 画面の案内に従って時間を置く。続けて試さず管理者へ連絡する |
| パスワードを忘れた | 下の再設定手順を使う。新しい職員を追加し直さない |

### パスワードを再設定する

1. 管理者が本人確認後、対象職員の「認証管理」で理由を入力し、**「再設定コードを発行」**を押します。
2. 本人にコードと、施設URLの後ろに `/staff/reset-password` を付けたURLを渡します。
3. 本人が再設定コードと新しいパスワード・確認用パスワードを入力し、**「パスワードを再設定」**を押します。
4. 新しいパスワードでログインします。再設定コードも30分・1回限りです。

更新版では再設定コードの発行後にも**「QR付き案内を印刷」**が表示されます。本人には再設定用の用紙を渡してください。QRは再設定画面を開きます。ログインIDは変わりません。

管理者本人がログインできない場合は、職員ログイン画面の**「管理者の方：パスワードを忘れた場合」**を使います。登録メールで復旧できない場合は運用担当者へ連絡してください。
