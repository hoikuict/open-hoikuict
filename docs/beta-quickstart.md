# かんたん導入で試す

このページでは、Windows 11の導入アプリで、まず架空データを使ってこのPCだけで試す手順を説明します。
Python・Gitの個別導入、コマンド入力、設定ファイルの編集は不要です。

[Windows用アプリをダウンロード](https://github.com/hoikuict/open-hoikuict/releases/latest/download/OpenHoikuICT.exe){ .md-button .md-button--primary }
[対応PCと配布内容](download.md){ .md-button }

## はじめる

1. [公式の配布ページ](https://github.com/hoikuict/open-hoikuict/releases/latest)から **OpenHoikuICT.exe** をダウンロードします。
2. 実行ファイルを開き、「このPCに導入する」を選びます。GitHubの検証済み最新版から、導入する版と変更内容を確認します。
3. ブラウザーで「次へ」を押し、**名前・メールアドレス・パスワード・確認**を入力します。
4. 内容を確認して「ダウンロードして準備」を押します。必要なPythonとソフトも自動取得するため、初回はインターネット接続が必要です。
5. 導入ホームの「起動してログイン画面を確認」を押し、設定したメールアドレスとパスワードでログインします。

メールアドレスは既定のログインIDです。この試用では実際のメールを送りません。
ログインIDや導入の記録、保存場所は必要なときだけ詳細欄で変更できます。

「配布版はまだ公開されていません」と表示された場合は、配布の準備ができてから「もう一度確認」を押してください。通信失敗は入力を保持してやり直せます。確認後に新しい版が公開された場合は、導入する版をもう一度確認します。

## 次回使う・終了する

- 次回は、完了画面に表示された**保存先にある OpenHoikuICT.exe** を開きます。初期設定は繰り返しません。
- 導入後は保存した版を起動します。毎回GitHubから取り直すことはありません。既存環境を新版へ上書きする機能は含みません。
- 一時的に止めるときは「試用アプリを停止」。終えるときは画面下の「導入アプリを終了」を使います。このPCだけの試用では、保育ICTの起動も停止します。
- ブラウザーのタブを閉じるだけではアプリは停止しません。同じ実行ファイルを開くと操作画面へ戻れます。
- 記録は保存先に残ります。実行ファイルだけを別の場所へ移さず、`app`・`runtime` と一緒に保管してください。

## やり直したいとき

- 「戻る」「変更」では入力を保ったまま修正できます。ページの再読込では未確定の入力が消えます。
- 中断や失敗では、作成途中の専用フォルダーを片付けます。片付けられなかった場合は場所を画面に表示します。
- 既存のファイルがある保存先には導入しません。別の**まだ存在しない**専用フォルダーを選んでください。
- 準備済みの環境へ再導入したり、パスワードやデータを作り直す処理は行いません。

## この試用版の範囲

このページの手順は、Windows 11 x64のPC内だけの試用です。Ubuntu向けの導入アプリは配布していません。

次は同じアプリから、[園内LAN・園外利用の設定](windows-server-setup.md)へ進めます。園内LANの設定で、自動起動・HTTPS・メール・定期バックアップを準備します。園内サーバーは導入画面を閉じた後も動作します。キオスクとWeb Pushは別途設定が必要です。業務画面は既存アプリと同じく外部配信のCSS・JavaScriptを利用するため、インターネット接続が必要です。Pythonと依存ソフトは検証済みの組み合わせをまとめて取得し、個別の導入作業を不要にします。

データを退避するときはアプリを終了し、保存先フォルダー全体をコピーします。設定と秘密鍵も含むため、管理できる場所に保管してください。

手動で認証版を起動する際は、[環境別の設定](environment-profiles.md)を参照してください。

ログイン後は[利用開始マニュアル](start-manual.md)に沿って、初期台帳のExcel準備・登録と保護者の利用開始へ進みます。
