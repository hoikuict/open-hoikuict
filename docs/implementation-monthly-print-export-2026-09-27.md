## 実装した動作

- 編集画面の「印刷用PDF」「Excel出力」と、保存済み文書の「印刷」に対応。
- 0〜2歳の個人別、3〜5歳の集団様式をA4横へ出力。全園児・全項目と長文の続きページを含める。
- 印刷確認画面とPDFは共通の固定グリッドを使う。確認画面はSVGで描画し、同梱のNoto Sans JPを使う。
  PDFには日本語フォントを埋め込む。操作欄・候補・履歴は帳票に含めない。
- Excelは1ページ1シートの編集可能なセル。罫線・セル結合・A4横・印刷範囲を設定。
  表示用改行を含め、先頭の `=` やURLも数式・リンクに変換しない。
- 編集画面は出力ボタンを押した時点の入力、閲覧画面は保存済みの本文・名簿を使う。
  出力ではDBの保存・承認・版更新をしない。出力ファイルや一時URL用キャッシュをサーバーに残さない。
- 園児の氏名・生年月日・名簿・クラス名はサーバーで解決する。
  未保存の本文を送信できるのは編集可能な職員だけ。対象文書の状態と版も確認する。
- 出力にはログイン・園・クラスの権限とCSRF検証を適用。園やクラスが異なる出力、存在しない園児・欄を拒否する。
- JSON APIは `/plans/monthly-library/export`、画面の出力は `/plans/monthly-library/export-file` へのPOST。
  ネイティブHTMLフォームによる応答で印刷画面とファイルを返し、ブラウザー内のblob URLに依存しない。
  失敗時は出力側のタブに理由を表示し、元の編集内容を保持する。
- 1回300人・本文合計50万文字・100ページ以内、プロセス内同時生成1件に制限する。
  生成中の追加要求は429で再試行を案内する。ブラウザーの出力要求後は入力を続けられる。
- PDFのダウンロード時は、保持した本文のスナップショットで再生成し、権限・文書の版を再確認する。
  他の職員が保存・承認した場合は再出力を案内する。最新の名簿が変わった場合はその名簿を使う。

## 依存と配備時の留意点

- Python依存にReportLab 4.4.9とXlsxWriter 3.2.9を追加。
- Noto Sans JPの静的Regular TTF（約5.8MB）とSIL OFLライセンスを `static/fonts/` に同梱。
  入手先・変換方法・SHA256は同ディレクトリのREADMEに記載。Windows専用フォントやPopplerは不要。
- PDF/印刷は同梱フォント、ExcelはMeiryoを指定する。Excel側で文章を増やした後は行高・改ページの再調整が必要な場合がある。
