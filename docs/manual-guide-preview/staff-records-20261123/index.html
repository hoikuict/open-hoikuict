職員ホームと児童票の手順

職員ホームで必要な情報を見つけ、児童票の保存・依頼・書き直しまで進むための5つの手順です。

1. 職員ホームの見方

日付・担当クラス、出欠、予定、文書の通知を確認します。

2. 要確認一覧の見方

件数の内訳、出欠・アンケートへの移動、0件の見方を確認します。

3. 児童票作成状況の見方

対象月と期間、未作成・下書きの探し方、担当による違いを確認します。

4. 児童票を入力する

5つの入力欄、参考記録、下書き保存、保存前の移動を確認します。

5. 児童票のレビューを依頼する

依頼、取り下げ、差戻し後の修正・再依頼を確認します。
