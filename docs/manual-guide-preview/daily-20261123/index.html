出欠と緊急連絡先の手順

出欠・登降園の確認と、園児別の緊急連絡順を、画面を見ながら確認できます。知りたい手順を選んでください。

職員向け

1朝の出欠を確認する・電話連絡を記録する

初回確認、理由付き変更、電話受付、受付取消

手順を確認する →職員向け

2登降園の時刻を補記・修正・取消する

時刻の補記・修正、保存後の確認、誤打刻の取消

手順を確認する →保護者向け

3いつもの緊急連絡順を登録する・その日だけ変える

通常の登録、並べ替え、その日だけの変更と戻し方

手順を確認する →職員向け

4緊急連絡先の変更を口頭で受け付ける

対象日・伝えた方、通常と当日の使い分け、履歴

手順を確認する →

実際の入力や連絡は、園のアプリで行ってください。
