# 保護者の方へ：登園・降園の使い方

園に着いたときと、お迎えのときに使うマニュアルです。
園にある受付用の画面で操作します。

[画面を見ながら読む](manual-guide-preview/index.html#parents){ .md-button .md-button--primary }

## 園に着いたとき（登園） {#arrival}

[登園の画面付き手順を開く](manual-guide-preview/index.html#article/parent-arrival){ .md-button }

1. お子さまの**クラス**を押します。
2. お子さまの**名前**を押します。下の名前まで見てください。
3. 名前が合っていたら、**「登園する」**を押します。
4. お迎えの**時間・来る人・補食**を選び、**「確認へ」**を押します。
5. 内容が合っていたら、**「決定」**を1回押します。
6. **「登園を受け付けました。」**と出たら終わりです。

「登園する」を押しただけでは、まだ終わりではありません。最後の表示まで見届けてください。

### お迎えの時間の入れ方

午後4時30分のお迎えなら、**「16時」→「30分」**の順に押します。
画面の「選択中」が **16:30** になったか見てください。

「補食」は、夕方などに食べる軽い食事です。「必要」か「不要」を選びます。迷ったら、職員に聞いてください。

すでに予定を入れていると、確認画面が先に出ることがあります。内容が合っていれば「決定」を押します。違っていれば「修正」で直します。

## お迎えのとき（降園） {#departure}

[降園の画面付き手順を開く](manual-guide-preview/index.html#article/parent-departure){ .md-button }

1. お子さまの**クラス**を押します。
2. お子さまの**名前**を押します。下の名前まで見てください。
3. 名前を確かめて、**実際に迎えに来た人**を選び、**「降園する」**を1回押します。
4. **「降園を受け付けました。」**と出たら終わりです。

朝の予定が「母」でも、お父さんが来たなら「父」を選びます。「降園する」を押すと、その時刻が記録されます。

**兄弟姉妹も、1人ずつ同じ操作をしてください。**

## 困ったとき {#help}

[困ったときの画面付き案内](manual-guide-preview/index.html#parent-help){ .md-button }

| こんなとき | すること |
| --- | --- |
| クラス・名前を間違えた | 決める前なら「最初に戻る」「名前選択へ」「取り消し」で戻ります。決めた後は、職員に訂正をお願いします。 |
| 名前が見つからない | クラスが合っているか見ます。見つからなければ職員に声をかけます。 |
| 登園なのに「降園する」と出る | 「降園する」は押さず、職員に確認します。 |
| お迎えなのに「登園する」と出る | 「登園する」は押さず、職員に確認します。 |
| 押すのを忘れた | 職員に、お子さまの名前と、園に着いた時刻・帰った時刻を伝えます。 |
| 画面が進まない・終わったか分からない | 何度も押さず、職員に記録を見てもらいます。 |
| 「本日の打刻は完了しています」と出る | 今日の降園は記録されています。時刻が違うときは職員に伝えます。 |
| お迎えの予定が変わった | 時間や、お迎えに来る人の変更を園へ伝えます。 |

「接続済み」と出ているだけでは、受付が終わったことにはなりません。
分からないときは、園の職員に声をかけてください。

---

このページは使い方の案内です。登園・降園を記録する画面ではありません。画面の名前・日付・時刻は説明用です。
