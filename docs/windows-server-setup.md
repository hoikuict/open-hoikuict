# Windowsで、このPCから園内LAN・園外利用へ進む

対象は Windows 11 x64 です。導入アプリは、GitHubの配布版と必要なソフトを取得します。Git・Python・Dockerを個別に入れる必要はありません。

[Windows用アプリをダウンロード](https://github.com/hoikuict/open-hoikuict/releases/latest/download/OpenHoikuICT.exe){ .md-button .md-button--primary }
[配布内容・対応PC](download.md){ .md-button }

v2026.9.23.4（2026年9月23日）を基準にした手順です。

## 1. このPCで試す

1. 導入アプリを開き、「このPCに導入する」を選びます。
2. 表示された配布版と保存先を確認します。導入済みのフォルダーには上書きしません。
3. 管理者の名前・メール・パスワードを入力します。必要ならログインID・作成理由・実行者・承認者を指定します。
4. 確認画面で「ダウンロードして準備」を押します。
5. ログインし、架空データで操作を確認します。この段階はPC内だけでの試用です。メールは外部に送信されません。

初期台帳は、取込用Excelの入園日など必須項目を確認してから取り込みます。配布アプリや公開マニュアルに園児の個人情報は含めません。

## 2. 園内LANで使う

### 先に用意するもの

- 園内で常時使えるPCと、Windowsの管理者権限。
- ルーターのDHCP予約などで固定した、このPCのIPv4アドレス。
- このPCにつながる園内DNSの名前。ルーター・DNSの操作は機種ごとに異なるため、アプリ外で設定します。
- STARTTLSに対応したSMTPサーバー、送信元アドレス、確認メールを受信するアドレス。
- バックアップ用のローカルドライブ。アプリ・DBとは別の保存先を指定します。共有・割当ドライブは対象外です。

Windowsのネットワークを「プライベート」にします。Wi-Fiを選ぶ場合も、利用端末からこのPCに接続できる園内ネットワークを使用します。

### HTTPSの選択

| 方法 | 必要な作業 |
| --- | --- |
| 園用ドメイン | Cloudflareで管理するドメインを用意します。対象Zoneの読取とDNS編集に絞ったAPIトークンを指定します。園内DNSはこのPCを指すよう設定します。証明書はDNS認証で取得・更新します。 |
| 園内専用証明書 | `hoikuict.home.arpa` などの名前を園内DNSに登録します。適用後、アプリから公開証明書を保存し、使用する各PC・タブレットに信頼する証明書として登録します。アプリは端末の信頼設定を自動変更しません。 |

ブラウザーの証明書警告を無視して利用する運用にはしません。園内専用証明書の登録方法は、端末の管理方式に合わせて確認します。

### アプリでの操作

1. 「園内LANを設定する」を選び、園名と使用するネットワークを指定して事前確認します。
2. 園内接続の8つの案内を進めます。接続の確認 → IPの固定予約 → アドレスの方式 → 開く名前 → 暗号化の準備 → 園内DNS → 準備の確認、の順です。最初の画面で作業の見通しを説明します。
3. GmailまたはほかのSMTPを選び、確認メールを1通送信します。実際に受信してから次へ進みます。Gmailの手順は下に記載します。
4. 保存先・毎日のバックアップ時刻・保存期間を選び、書込みを確認します。期間を過ぎても直近2件は保持します。
5. 確認画面で適用します。ここでWindowsの管理者許可を求めます。
6. アプリがデータ・添付・認証鍵を引き継ぎ、Windowsサービス・HTTPS・園内接続・バックアップを設定します。元の試用データは保持し、旧データでの起動を防止します。
7. 別の端末からのログイン、Windows再起動後の接続、バックアップから別の場所への復元を確認します。すべて確認してLAN設定を完了します。

サービスはWindowsログイン前から起動します。電源接続中の自動スリープを止める選択肢があります。PCの電源断・休止・ネットワーク断の間は利用できません。

接続許可は選択したプライベートネットワークとIPv4範囲のTCP 443に限定します。アプリ本体・制御用ポートはPC内だけで待ち受けます。

### 園内接続で迷ったとき

**IPの固定予約と、名前の登録は別の設定です。** たとえば「このPCにいつも `192.168.0.10` を割り当てる」がDHCP予約、「`hoikuict.home.arpa` を開くと `192.168.0.10` につながる」が名前の登録です。数字のIPを予約しただけでは、名前の確認は通りません。

1. 「PCの接続先」が確認済みなら、IPの予約を繰り返す必要はありません。
2. 「名前からPCを探す」が要確認なら、園内DNSに、入力した名前とこのPCのIPが登録されているか確認します。ルーターに名前を登録する機能がない場合は、ネットワーク担当者に相談します。
3. まずこのPCだけで試す場合は、担当者がこのPCの `hosts` に名前とIPを登録する方法もあります。この設定はこのPCだけに有効です。他のPCやiPadからの接続確認は別途必要です。
4. 登録後に「もう一度確認する」を押します。名前の確認が通っても、証明書の登録と実際のHTTPS接続の確認は続けて行います。

PCの名前・IP・MACアドレス・ゲートウェイを読み取って表示します。ゲートウェイはルーターの管理画面と同じとは限らないので、機種の説明書や担当者に確認します。「担当者に相談する」で、現在の名前とIPを含む依頼文を表示できます。アプリから自動送信はしません。

最後の準備確認では、PCの接続・名前解決・暗号化の準備を別々に表示します。失敗した項目から関連する手順へ戻れます。Cloudflareのトークン確認は、有効性と対象ドメインの参照までです。DNSの書込みと証明書の発行、実際のHTTPS接続は、設定を適用するときに確認します。

「引継ぎ元と配布版を確認」で「Windowsの設定操作を完了できませんでした」と表示される旧試用版の不具合は、v2026.9.23.4で修正しました。旧画面の「導入アプリを終了」で閉じ、[最新版](download.md)を通常起動して、同じ保存先のLAN設定を再開してください。保存先フォルダーの削除や管理者アカウントの作り直しは不要です。パスワード・トークンと接続確認はやり直します。

同じ修正版で、サービス専用アカウントへの切替と、サービスの停止・再起動も修正しています。停止中はWindowsが停止完了を確認するまで待ち、処理途中でデータ移行や再起動へ進みません。

v2026.9.23.4は園内サーバー設定に対応した配布版です。最終適用時にGitHubの公開版を検証して取得するため、インターネット接続が必要です。

### Gmailで送る場合

1. メールの種類で「Gmailを使う」を選びます。接続先 `smtp.gmail.com`、587、STARTTLSが設定されます。
2. 園で管理できる送信元アドレスを入力します。Gmailへ接続するIDにも同じアドレスを使います。
3. そのGoogleアカウントで2段階認証が有効か確認します。[Google公式の2段階認証の手順](https://support.google.com/accounts/answer/185839?hl=ja)に沿って準備します。
4. Googleで「オープン保育ICT」用のアプリパスワードを作り、16文字を入力します。通常のGoogleログイン用パスワードとは別です。[Google公式のアプリパスワードの説明](https://support.google.com/accounts/answer/185833?hl=ja)を参照してください。
5. 自分で開ける確認先を入力し、「確認メールを送る」を押します。送信元と同じ宛先も指定できます。届いたことを確認してチェックし、次へ進みます。

Google Workspaceなど組織の設定や保護機能によってはアプリパスワードを使えません。作れない場合は管理者に相談し、STARTTLSに対応した別の送信方法を用意します。Gmailは園内だけの利用でも、サーバーPCからインターネットへの接続が必要です。

認証エラーではアプリパスワードの説明へ戻れます。送信元を変更したときは、新しいGoogleアカウントの準備とパスワード入力をやり直します。Googleの通常のパスワードを変更すると、発行済みのアプリパスワードも無効になるため、再発行が必要です。

ほかのSMTPを選ぶと、従来のサーバー名・ポート・ログインID・パスワード・送信元・確認先を入力できます。方式を切り替えたときの入力は画面内で保持しますが、送受信確認はやり直します。

## 3. 園外からも使う

1. 園内LANの動作確認を完了してから「園外からの利用を設定」を選びます。
2. 公開用ホスト名を指定します。園用ドメインでLANを設定した場合は同じ名前を使います。
3. Cloudflare側でこの園用のTunnelと公開ホスト名を作ります。接続先はアプリに表示された `HTTP / 127.0.0.1:ポート番号` に設定します。
4. 接続用トークンを入力して形式を確認します。トークンの認証と実際の接続は利用開始時に検査します。
5. 確認画面で開始します。公開URLがこのPCに到達するか検査します。
6. 園内Wi-Fiを切った携帯回線などでログインとメール内リンクを確認し、園外利用の確認を完了します。

ルーターのポート開放は不要です。Cloudflareアカウント・ドメインの契約やDNS設定はアプリ外で行います。

園内専用証明書から進んだ場合、園内URLと公開URLが異なります。登録・再設定メールには公開URLを使用します。公開開始だけで保護者に一斉案内を送りません。

## 中断・停止・再開

- 入力中の中断では、現在の利用状態を維持します。LAN・園外設定の下書きから秘密情報を除いて保存します。園内接続・Gmail案内は中断した手順から再開できます。パスワードやトークンは画面を閉じると再入力が必要で、接続や送受信の確認もやり直します。
- 「この接続設定を取り消す」は、アプリ内の接続入力を開始時へ戻します。ルーターなどの外部画面で保存した変更は、中断・取消では元に戻りません。
- 設定変更後に事前確認の対象項目を変えると、確認をやり直す必要があります。
- 適用途中の失敗では、今回のサービス・接続設定を可能な範囲で戻します。復旧できない場合は、成功と表示せず、データを保持して再適用を止めます。
- 利用開始後に問題が起きても、古い試用DBに自動的に戻して新しい記録を失う処理は行いません。
- 「園外からの利用を停止」では、短時間のサービス再起動を行い、園内運用を続けます。登録・再設定メールの送信を保留します。通常の連絡メールは継続します。
- 再公開時は接続と公開URLを再確認します。未送信の認証メールは現在のURLに合わせます。有効期限が切れたコード等は業務画面から再発行します。

## 保存先と運用

- プログラム：`C:\Program Files\OpenHoikuICT\導入ID`
- DB・添付・接続設定：`C:\ProgramData\OpenHoikuICT\導入ID`
- バックアップ：指定先の `open-hoikuict-導入ID`
- 操作用情報：最初に導入したフォルダーの `.server-setup`

サービスは専用の権限が限定されたWindowsアカウントで動作します。接続用の秘密情報はWindows DPAPIとフォルダー権限で保護します。公開証明書を除く鍵ファイルや設定ファイルを公開・共有しないでください。

日々のバックアップにSMTP・Cloudflare等の接続設定は含めません。新しいPCに移す場合はそれらの再設定が必要です。元の試用フォルダーは導入アプリの管理情報も含むため、LAN化した後に手動で移動・削除しません。

導入済みの業務環境の自動更新、他PCへの一括移転、アンインストールはこの画面の対象外です。配布アプリは新規導入時とLAN化時に対応する配布版を検証して取得します。
