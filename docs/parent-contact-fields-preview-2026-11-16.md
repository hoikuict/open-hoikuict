## 要望と解釈

**確認できた要望**：保護者が記入する連絡項目を年齢・クラスごとに選択したい。体温・食事などは低年齢だけでよく、施設ごとに異なってもよい。「手稲令」は「低年齢」の意味であることを同日の回答で確認した。

**当方の解釈・試用案**：施設ごとに「年齢ごと」「クラスごと」のいずれか一つを選び、各項目を「表示する／表示しない」の二択で指定する。年齢方式は同じ年齢なら別クラスでも同じ項目、クラス方式は混合クラスでも全員同じ項目になる。方式の選択自体も仮保存の対象。「施設共通」「引き継ぐ」や優先順は設けない。年齢は年度の年齢と仮定。初期見本 A の年齢方式は0〜2歳で全項目、3〜5歳で体温・睡眠・夕食・朝食・排便・機嫌を非表示。クラス方式の見本は、さくら組のみ同じ6項目を非表示、他のクラスは全項目を表示する。見本 B は全項目を表示する。0〜2歳という区切りと、体温・食事以外の省略項目は未合意。

## 画面・保存・修正

| 操作 | モックで試す動作 |
| --- | --- |
| 園の設定 | 最初に「年齢ごと／クラスごと」を一つ選ぶ。年齢なら0〜5歳の6列、クラスなら4クラスの列を並べ、各項目を表示／非表示で指定 |
| 方式を切り替える | 両方式の入力を別々に保持し、仮保存した方式のみを保護者画面へ適用。切替自体では保存しない。年齢・クラス間で値を自動変換しない |
| 保存前の表示を確認 | 未保存の設定で保護者画面を開く。設定未保存であることを明示し、日次連絡の仮保存ボタンは無効 |
| 設定を仮保存して入力画面へ | 選択中の施設だけに保存。新しく記入する連絡に適用し、他施設には影響しない |
| 設定の変更を取り消す | 選択中施設の方式と各項目を最後の仮保存状態へ戻す |
| 保護者の入力 | 配備記録に対応する現行フォームを使用。選択項目以外の既存入力欄を省略せず、入力順・全体の長さも確認できる |
| 日次連絡を保存する | このタブ内に園児・日付ごとの内容と表示項目を仮保存。職員の受け取り・保護者履歴に反映。入力途中は職員には表示しない |
| 今回の入力を取り消す | 新規なら空欄、修正中なら仮保存済み内容へ戻す。提出済みレコード全体の取消ではない |
| 保存済み連絡の修正 | 保存時の表示項目を保持して修正する案。設定変更で以前の入力内容を消さない。新しい連絡日は変更後の設定を使用 |
| 職員の受け取り | 出欠・連絡内容を表示。「未入力」と「対象外（保存時の設定）」を区別。今回の受け取り画面は詳細の確認用で、業務一覧全体の再現ではない |

選択対象は、体温、睡眠（就寝・起床・メモ）、前日の夕食（食欲・食べたもの）、当日の朝食（同）、排便（性状・回数・メモ）、機嫌、咳、鼻水、服薬、体調メモの10組。項目内をさらに分割する操作は未提案。

出欠、緊急連絡先、お迎え予定（時刻・人・補食）、園への連絡事項、欠席の入力欄は全員共通として残す案。病欠の体温・症状は従来どおり必須。通常連絡の体温を表示する場合、37.5℃以上の出席保存を止める現行判定を引き継ぐ。表示しない項目に新しい必須条件は設けない。緊急連絡順の初回登録・口頭受付・共有権限は今回の変更範囲外。

## 試し方と未確定事項

ローカル入口は `http://127.0.0.1:8117/`。単体ファイルは `tools/parent-contact-fields-preview/index.html`。

1. 「園の設定」で年齢ごとの項目を選び、仮保存して入力画面へ進む。
2. 上部の試用欄で「ひよこ組・1歳児」と「さくら組・3歳児」を切り替え、欄の違いを確認する。
3. 園の設定で「クラスごと」を選び、クラス別の表示を指定して仮保存する。混合クラスの2歳児・3歳児で同じ項目になることを比較する。「年齢ごと」に戻して仮保存すると、それぞれの年齢の設定を使う。
4. 「試用する入力状態・検討中の扱い」を開き、未入力・入力済み・一部入力・エラーを選んで見本を入れ直す。この操作だけは対象園児・日の仮記録を置き換える。
5. 保存後に「職員の受け取り」へ移動。設定を変えた後、同じ日と翌日を比較する。

**次に確認する事項**：施設全体で方式を一つ選ぶという解釈、方式切替時に両表の入力を保持する扱い、年齢の区切りと基準日、共通で残す項目、睡眠・排便などをまとめる単位、設定担当者の権限、設定の適用開始日、既存連絡の編集時の項目、進級・転組・同時編集時の扱い。いずれもモックの実装を最終合意の根拠としない。
