# ダウンロード

WindowsのPCでの試用から、園内LAN、園外からの利用へと段階的に進める導入アプリです。開くとGitHubで公開している検証済みの最新版を確認し、必要なソフトをまとめて準備します。PythonやGitを個別にインストールする必要はありません。

[Windows用アプリをダウンロード](https://github.com/hoikuict/open-hoikuict/releases/latest/download/OpenHoikuICT.exe){ .md-button .md-button--primary }
[利用開始マニュアルを読む](start-manual.md){ .md-button }

| 項目 | 内容 |
| --- | --- |
| 対応PC | Windows 11・64ビット（x64） |
| 保存するファイル | `OpenHoikuICT.exe` |
| 配布元 | [公式GitHub Releases](https://github.com/hoikuict/open-hoikuict/releases/latest) |
| 確認済みの配布版 | [v2026.9.23.5](https://github.com/hoikuict/open-hoikuict/releases/tag/v2026.9.23.5)（2026年9月23日） |
| ダウンロードサイズ | この版の導入アプリは約10.8MB。初回の準備時に本体約109.4MBを追加取得します。 |
| インターネット接続 | 初回の最新版確認・取得に必要です。業務画面も外部配信の表示用ファイルを使用します。 |

ボタンからは最新の公開版をダウンロードします。ブラウザーのダウンロード一覧で、ファイル名が **OpenHoikuICT.exe** になっていることを確認してください。

## ダウンロードした後

1. `OpenHoikuICT.exe` を開き、「このPCに導入する」を選びます。
2. 画面に表示された導入する版と変更内容を確認します。
3. 管理者の名前・メールアドレス・パスワードを入力します。
4. 確認画面で「ダウンロードして準備」を押します。
5. 準備が完了したら、導入ホームの「起動してログイン画面を確認」から、登録した情報でログインします。

詳しい操作、停止・再起動、通信エラー時の対応は[かんたん導入](beta-quickstart.md)にあります。ログインできたら、[利用開始マニュアル](start-manual.md)に沿って台帳の準備へ進みます。

## このアプリで準備できる範囲

| 段階 | アプリで進めること |
| --- | --- |
| このPCで試す | 管理者を作成し、架空データで操作を確認します。この段階では実メールを送りません。 |
| 園内LANで使う | データを引き継ぎ、Windowsサービス、自動起動、HTTPS、SMTP、定期バックアップを設定します。IPの固定予約・名前の登録・証明書の準備を順に案内します。 |
| 園外からも使う | 園内の動作確認後にCloudflare Tunnelを設定し、公開URLと園外からの接続を確認します。 |

[Windowsの段階別導入手順](windows-server-setup.md)で、ルーターの設定、Gmailの準備、中断・再開も説明しています。ルーターやGoogle・Cloudflare側の設定、端末への証明書登録は画面の案内に沿って行います。キオスクとWeb Pushは別途設定が必要です。

実際の園児・保護者の情報を扱う前に、利用端末からの接続、PC再起動後の接続、メール受信、バックアップと復元を園の環境で確認します。

新規導入時と園内LANへの切替時に、対応する配布版を検証して取得します。導入後の通常起動では保存先にある版を使います。稼働中の業務環境を新版へ自動更新する機能は含みません。

## ダウンロード・準備が進まないとき

| 状況 | 対応 |
| --- | --- |
| ボタンから取得できない | [配布ページ](https://github.com/hoikuict/open-hoikuict/releases/latest)を開き、Assetsの `OpenHoikuICT.exe` を選びます。 |
| 最新版の確認に失敗した | インターネット接続を確認し、導入画面の「もう一度確認」で再試行します。 |
| Windowsの警告や組織の実行制限が出る | ファイル名と配布元を確認し、PCの管理者に相談します。 |
| LAN設定の最初で「Windowsの設定操作を完了できませんでした」と出る | v2026.9.23.4で修正しました。旧画面の「導入アプリを終了」で閉じ、最新版を開き直して同じ保存先の設定を再開します。データフォルダーの削除や新規導入のやり直しは不要です。詳しくは[中断・再開](windows-server-setup.md)を参照してください。 |
| 既存の保存先を使えない | 保存済みデータを残し、新規試用にはまだ存在しない専用フォルダーを指定します。 |
| LAN設定の最後で「サーバーの導入情報を読み取れません」と出る | v2026.9.23.5で再発を防ぐ修正を行いました。旧版で発生した場合、サービス自体は設定済みの可能性があります。保存先を削除したり再導入したりせず、担当者が導入記録の読み取り権限を修復してから動作確認へ進みます。 |
| 導入する版が変わったと表示された | 新しく表示された版と変更内容を確認してから進みます。 |

macOS・Windows ARM向けの導入アプリは配布していません。Ubuntuは[手動の導入手順](beta-installation-linux.md)を参照してください。
