# ダウンロード

WindowsのPCでオープン保育ICTを試せる導入アプリです。開くとGitHubで公開している検証済みの最新版を確認し、必要なソフトをまとめて準備します。PythonやGitを個別にインストールする必要はありません。

[Windows用アプリをダウンロード](https://github.com/hoikuict/open-hoikuict/releases/latest/download/OpenHoikuICT.exe){ .md-button .md-button--primary }
[利用開始マニュアルを読む](start-manual.md){ .md-button }

| 項目 | 内容 |
| --- | --- |
| 対応PC | Windows 11・64ビット（x64） |
| 保存するファイル | `OpenHoikuICT.exe` |
| 配布元 | [公式GitHub Releases](https://github.com/hoikuict/open-hoikuict/releases/latest) |
| 確認済みの配布版 | v2026.9.23.1（2026年9月23日） |
| ダウンロードサイズ | この版の導入アプリは約9.4MB。初回の準備時に本体約73.5MBを追加取得します。 |
| インターネット接続 | 初回の最新版確認・取得に必要です。業務画面も外部配信の表示用ファイルを使用します。 |

ボタンからは最新の公開版をダウンロードします。ブラウザーのダウンロード一覧で、ファイル名が **OpenHoikuICT.exe** になっていることを確認してください。

## ダウンロードした後

1. `OpenHoikuICT.exe` を開きます。
2. 画面に表示された導入する版と変更内容を確認します。
3. 管理者の名前・メールアドレス・パスワードを入力します。
4. 確認画面で「ダウンロードして準備」を押します。
5. 準備が完了したら「起動して開く」を押し、登録した情報でログインします。

詳しい操作、停止・再起動、通信エラー時の対応は[かんたん導入](beta-quickstart.md)にあります。ログインできたら、[利用開始マニュアル](start-manual.md)に沿って台帳の準備へ進みます。

## このアプリで準備できる範囲

**このPCだけで架空データを使うローカル試用版**です。管理者の作成とアプリの起動までを準備します。メールは実際には配送されません。

園内の複数端末からの接続、保護者向けの公開HTTPS、メール配送、キオスク、Web Push、自動起動は別途設定が必要です。園の実データを扱う環境は、[導入方法](getting-started.md)と[本番設定](security.md)に沿って担当者が準備します。

導入後は保存先にある版を起動します。毎回最新版を取り直す仕組みではなく、既存環境を上書き更新する機能も含みません。

## ダウンロード・準備が進まないとき

| 状況 | 対応 |
| --- | --- |
| ボタンから取得できない | [配布ページ](https://github.com/hoikuict/open-hoikuict/releases/latest)を開き、Assetsの `OpenHoikuICT.exe` を選びます。 |
| 最新版の確認に失敗した | インターネット接続を確認し、導入画面の「もう一度確認」で再試行します。 |
| Windowsの警告や組織の実行制限が出る | ファイル名と配布元を確認し、PCの管理者に相談します。 |
| 既存の保存先を使えない | 保存済みデータを残し、新規試用にはまだ存在しない専用フォルダーを指定します。 |
| 導入する版が変わったと表示された | 新しく表示された版と変更内容を確認してから進みます。 |

macOS・Windows ARM向けの導入アプリは配布していません。Ubuntuは[手動の導入手順](beta-installation-linux.md)を参照してください。
