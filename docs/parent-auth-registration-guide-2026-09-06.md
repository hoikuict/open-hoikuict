# 保護者認証・登録手順書

作成日：2026-09-06<br>
対象：OPEN保育ICT、保護者のローカルパスワード認証<br>
確認した実装：`c759415960d4eae04401cd28c2e3f967868279e4`

既存資料とは別に作成した、現在の実装に基づく手順書です。通常は、園が保護者アカウントと閲覧対象の園児を登録し、**メール招待 → 保護者の本人情報入力 → 園の承認 → 保護者のパスワード設定**の順に利用を開始します。

メールを使わず、園で本人確認して初回設定コードを交付する経路も実装されています。そちらは第6章を使用します。管理者のログイン準備は[職員認証・登録手順書](staff-auth-registration-guide-2026-09-06.md)を参照してください。

## 1. 登録方式と担当者

| 方式 | 園が行うこと | 保護者が行うこと |
|---|---|---|
| 通常のメール招待 | 台帳・園児紐付けを登録し、招待メールを送る。本人情報の照合結果を確認して承認する | 招待メールから本人情報を入力。承認後の2通目のメールからパスワードを設定する |
| 初回設定コード | 台帳・園児紐付けを登録し、園の方法で本人確認後に6文字のコードを交付する | 専用画面でコードを入力してパスワードを設定する |

台帳の作成・編集には「園児台帳管理」の権限、招待・承認・コード発行には「管理者」の権限が必要です。同じ担当者が一連の操作を行う場合は、両方を持つ職員アカウントを使います。

**園児台帳に保護者の氏名が載っていること、家族に所属していること、保護者アカウントを作ったことは、それぞれログインの登録完了とは異なります。**

## 2. 登録前の環境確認［サーバー担当者］

### 2.1 利用URL・認証モード

本書の「施設URL」は、本人の端末から実際にアクセスできるURLです。例の `https://hoiku.example.jp` は施設のURLへ置き換えてください。

| 用途 | パス |
|---|---|
| 園側の保護者アカウント一覧 | `/parent-accounts/` |
| 保護者ログイン | `/parent-portal/login` |
| 初回設定コードの入力 | `/parent-portal/activate` |
| 再設定コードの入力 | `/parent-portal/reset` |

起動中のアプリで以下を確認します。

```dotenv
HOIKUICT_ENABLE_MOCK_AUTH=0
HOIKUICT_STAFF_AUTH_MODE=local_password
HOIKUICT_PARENT_AUTH_MODE=local_password
```

保護者を選ぶだけの画面はモック認証です。本書は保護者本人がメールアドレスとパスワードでログインする環境を対象とします。

### 2.2 メール招待を使う場合

| 設定 | 確認内容 |
|---|---|
| `HOIKUICT_PARENT_MAIL_TRANSPORT` | 実際にメールを送る環境は `smtp` |
| `HOIKUICT_PARENT_REGISTRATION_BASE_URL` | 本人がアクセスできる施設URL。プロトコル・ホスト名・ポートを実際のアクセス先に合わせる |
| `HOIKUICT_SMTP_HOST` / `HOIKUICT_SMTP_PORT` | 使用するメールサーバーとポート |
| `HOIKUICT_SMTP_STARTTLS` | 使用するSMTP構成に合わせる。サーバー仕様書の例では `1` |
| `HOIKUICT_SMTP_USERNAME` / `HOIKUICT_SMTP_PASSWORD` | SMTP側が認証を要求する場合の資格情報 |
| `HOIKUICT_PARENT_MAIL_FROM` | 送信元メールアドレス |

設定変更はサーバー担当者が行い、アプリを再起動して反映します。全体の本番設定は[サーバー稼働仕様書v2](pilot-deployment-spec-v2.md)を参照してください。上表だけで本番起動条件が揃うわけではありません。

**認証版βのサンプル設定は `capture` です。`capture` はメールを実送信せず、アプリ内に検証用の配送記録を保持します。保護者の受信箱には届きません。現在の認証管理画面には、そのメール本文を読む画面もありません。** SMTP未準備の画面操作試験は合成データで第6章を使い、メール経路の確認はSMTPを準備して別途実施します。

また、`.env.beta.example` の登録URL例は `http://localhost:8000` ですが、`start_beta.ps1` の既定ポートは `8001` です。同じPCで `http://127.0.0.1:8001` を使うなら、登録URLもそれに合わせます。スマートフォンの `localhost`・`127.0.0.1` はスマートフォン自身を指すため、サーバーのURLとして案内しないでください。β起動スクリプトは既定でサーバーPC内だけから接続できます。

## 3. 園が台帳と閲覧対象を準備する

### 3.1 園児の照合情報を確認する

1. 園児一覧から対象園児の編集画面を開きます。
2. 次の項目を入力・確認して保存します。

| 園児側の項目 | 入力内容 |
|---|---|
| 保護者登録の照合用氏名 | 本人確認に使う園児のカナ氏名または英字氏名 |
| 照合表記 | 「カナ」または「英字」。未設定のままにしない |
| 生年月日 | 当該園児の正しい生年月日 |

通常の氏名・フリガナ欄とは別に、登録照合用の項目があります。通常のフリガナ欄に値があるだけでは登録照合の準備は完了しません。

### 3.2 保護者アカウントを作成する

1. 「保護者アカウント」(`/parent-accounts/`) から新規登録画面 (`/parent-accounts/new`) を開きます。既に登録済みの保護者は編集画面を使います。
2. 以下を入力します。

| 保護者側の項目 | 入力内容 |
|---|---|
| 表示名 | 対象保護者の氏名 |
| メールアドレス | 本人の登録メールアドレス。保護者のログインIDにもなる |
| 登録照合用氏名 | 本人確認済みの保護者のカナ氏名または英字氏名 |
| 照合表記 | 登録照合用氏名に合わせて「カナ」または「英字」 |
| 状態 | 「有効」 |
| 所属家族 | 該当する家族があれば選択。家族への所属だけでは閲覧権限は付かない |
| 閲覧を許可する園児（明示的な紐付け） | この保護者に閲覧を許可する園児だけにチェックする |

3. 電話番号など必要な連絡先を入力し、新規なら「登録する」、編集なら「更新する」を押します。
4. 編集画面を開き直して、登録メールアドレス、照合情報、園児のチェックが保存されていることを確認します。

同じ家族でも、ログインする保護者ごとにアカウントと園児への紐付けを用意します。複数の保護者に同じログインIDを割り当てないでください。きょうだいを閲覧する場合は、それぞれの園児に明示的にチェックします。

招待には、少なくとも1人の紐付いた園児について、照合用氏名・照合表記・生年月日が揃っている必要があります。運用では対象園児全員の情報を整えてください。初回設定コードを使う場合も、この台帳条件は必要です。

## 4. 通常のメール招待で登録する

### 4.1 園：招待を送る

1. 管理者でログインし、保護者アカウント一覧の対象行から「認証管理」を開きます。
2. 対象保護者の氏名とメールアドレスを確認します。
3. 「初回登録の案内」の「招待理由」を入力します。例：「新規利用開始のため」。
4. 「招待を送信・再送」を押します。
5. 「登録申請の履歴」に「招待済み」が表示されることを確認します。

メールは送信待ちに登録され、アプリのメール処理が配送します。「招待済み」は受信箱への到着を保証する表示ではありません。

### 4.2 保護者：1通目のメールから本人情報を入力する

1. 件名「保護者ポータル 初回登録のご案内」のメールを開きます。
2. メールの登録リンクを発行から24時間以内に開きます。
3. 「本人情報の確認」画面で、以下を入力します。

   - 園に登録した保護者氏名（カナまたは英字）
   - 園に登録した園児氏名（カナまたは英字）
   - 園児の生年月日

4. 「園へ確認を依頼する」を押します。
5. 「園に確認を依頼しました」と表示されたら、園の確認を待ちます。この時点ではまだログインできません。

漢字の表示名ではなく、園が照合用に登録した表記を入力します。きょうだいがいる場合は、紐付け済みの園児1人の氏名と、その園児の生年月日で照合します。照合した1人だけに閲覧権限が限定されるわけではなく、閲覧対象は園が設定した明示的な紐付けで決まります。

リンクを開いた後の入力手続きには15分の有効期限があります。同じブラウザで続けて操作し、CookieとJavaScriptを使用できる状態にしてください。登録リンクの `#` 以降も必要な情報です。コピー時に切り落とさないでください。

### 4.3 園：照合結果を確認して承認する

1. 対象保護者の「認証管理」を開き直します。
2. 「登録申請の履歴」にある「確認待ち」の申請を確認します。
3. 「保護者氏名」「園児氏名」「生年月日」がすべて「一致」であることを確認します。台帳と現在の園児紐付け、登録メールの宛先も確認します。
4. 「確認理由」に確認内容を記録し、「承認」を押します。
5. 申請が「承認済み」になったことを確認します。保護者へパスワード設定の案内メールが送信待ちに登録されます。

**「確認待ち」と表示されるだけでは承認可能とは限りません。** 入力不一致の申請もこの状態になります。現在の画面には不一致でも「承認」ボタンが表示されますが、処理側が承認を拒否します。照合結果が不一致なら入力内容・台帳を確認し、必要に応じて却下・修正・再招待します。

### 4.4 保護者：2通目のメールからパスワードを設定する

1. 件名「保護者ポータル パスワード設定のご案内」のメールを開きます。最初の招待メールとは別のメールです。
2. 承認時の発行から24時間以内にリンクを開きます。
3. 「パスワード設定」画面で、新しいパスワードと確認用パスワードを入力します。
4. 「パスワードを設定する」を押します。リンクを開いた後は15分以内に設定を完了します。
5. 保護者ログイン画面で、**登録メールアドレスをログインIDとして**、本人が設定したパスワードでログインします。

パスワードは8〜128文字です。氏名・ログインID・メールアドレスを含むものや、拒否リストにある推測しやすいものは受け付けられません。画面の理由に従って別のパスワードに変更してください。保護者は初回設定画面で任意のログインIDを選ぶ方式ではありません。

## 5. 登録完了を確認する

園と保護者で、次を確認します。

- [ ] 本人が登録メールアドレスとパスワードでログインできる。
- [ ] 本人に許可された園児が表示され、必要なきょうだいが揃っている。
- [ ] 閲覧対象に誤りがある場合は利用を止め、園が紐付けを訂正する。
- [ ] 園の認証管理画面が「利用中」になっている。
- [ ] メール招待方式では、該当申請の履歴が「登録完了」になっている。
- [ ] ログアウト後も、同じログイン情報でログインできる。

コード方式はメール登録申請の履歴を経由しません。そちらの完了判定は「利用中」と本人のログイン結果で行います。

## 6. 初回設定コードで登録する［園で本人確認する場合］

メール配送を使わず初回設定する経路です。通常のメール招待に含まれる本人情報の入力・園の承認画面は通らないため、**コード発行前に園が本人確認と閲覧対象の確認を行います。** 理由欄に確認方法を記録してください。

### 園の操作

1. 第3章の台帳・照合情報・園児の紐付けを準備します。メールアドレスもログインIDとして必要です。
2. 管理者が対象保護者の「認証管理」を開きます。
3. 「初期設定・利用再開」の「発行理由」に、実施した本人確認と発行理由を入力します。
4. 「初回設定コードを発行」を押します。
5. 表示された6文字のコードと `施設URL/parent-portal/activate`、登録メールアドレスを本人へ個別に伝えます。

コードは発行から30分・1回限りです。画面を閉じた後に同じコードを再表示する機能はありません。本人の操作が可能なタイミングで発行します。

### 保護者の操作

1. 園から案内された `施設URL/parent-portal/activate` を開きます。
2. 「有効化コード」に6文字のコードを入力し、「コードを確認する」を押します。
3. 新しいパスワードと確認用パスワードを入力して、送信ボタンを押します。**現在の通常表示では、初回設定でもボタン名が「再設定する」になっています。** 入力エラー後の画面では「設定する」と表示される場合があります。
4. コード確認後は15分以内に設定を完了します。
5. `/parent-portal/login` で、登録メールアドレスと設定したパスワードでログインし、第5章の完了確認を行います。

既にパスワード設定済みで利用中の保護者には、初回設定コードを発行できません。パスワードを忘れた場合は第8章の再設定を使います。また、この経路を使っても、現在の `production` 起動条件にあるSMTP設定が不要になるわけではありません。

## 7. 有効期限と再発行

| 対象 | 期限・制限 | 進めない場合 |
|---|---|---|
| 1通目の招待リンク | 発行から24時間。リンクの検証は1回限り | 園に再招待を依頼 |
| 招待リンクを開いた後の本人情報入力 | 15分。照合は最大5回 | 中断・期限切れ・上限到達なら園へ連絡し、必要に応じて再招待 |
| 2通目のパスワード設定リンク | 承認時の発行から24時間。リンクの検証は1回限り | 園が再招待し、本人情報の確認・承認からやり直す |
| パスワード設定リンクを開いた後 | 15分 | 期限切れなら園へ連絡 |
| 初回設定・再設定コード | 発行から30分。コードの検証は1回限り | 園が用途に合ったコードを再発行 |
| コードを確認した後のパスワード設定 | 15分 | 期限切れなら園がコードを再発行 |
| 招待の再送 | 前回から60秒以上、直近24時間で最大10回 | 連打せず、宛先・配送状態・経過時間を確認 |

再招待すると、進行中の古いメール登録申請は取り消されます。保護者は最新の案内を使います。承認済みの人へ再招待すると、本人情報の確認と園の承認もやり直しになります。

園の担当者が動作確認のために本人用メールリンクを開くと、本人が使う前にリンクを消費する場合があります。本人用の登録リンクは本人の端末で開き、試験には別の検証用アカウントを使用してください。

## 8. うまく進まない場合・パスワード再設定

| 症状 | 確認・対処 |
|---|---|
| 招待で「保護者の照合用氏名と表記種別を登録してください」と出る | 保護者アカウントの「登録照合用氏名」「照合表記」を入力・保存 |
| 「明示的に紐付く園児へ照合用氏名と生年月日を登録してください」と出る | 園児へのチェックと、その園児の照合用氏名・照合表記・生年月日を確認 |
| 招待・承認が403になる | 管理者としてログインしているか確認。台帳の登録・編集には園児台帳管理権限も必要 |
| 招待メールが届かない | 宛先、迷惑メール、`capture` でないこと、SMTPとメール処理の稼働をサーバー担当者が確認。画面の「招待済み」だけで到着と判断しない |
| 本人情報を送信したが2通目が届かない | 園が該当申請を承認したか確認。送信後すぐに自動承認される方式ではない |
| 氏名・生年月日が一致しない | 表示用の漢字氏名と照合用氏名を区別。同じ園児の氏名・生年月日を入力。園側の登録内容と紐付けも確認 |
| メールリンクが開かない／手続きをやり直す表示になる | 発行期限・使用済み・最新の案内か・URLの `#` 以降が欠けていないかを確認。別ブラウザへの途中切替を避ける |
| スマートフォンでリンク先に接続できない | 登録URLが `localhost` になっていないか、本人の端末から到達できるかを確認。園内限定のサーバーなら園外からは利用できない |
| 登録後、園児が表示されない／きょうだいが足りない | 「所属家族」だけでなく、各園児の明示的な紐付けを確認 |
| パスワード設定済みなのにログインできない | 登録メールをIDとしているか、台帳の状態が有効か、認証停止されていないかを確認。連続失敗時は試行を止めて時間を置く |
| 「CSRFトークンが不正です」 | 正しい施設URLで画面を開き直し、Cookieを許可。同じ手続き中にホスト名を切り替えない |
| 初回設定コードを発行できない | 台帳条件と状態を確認。既に利用中なら初回設定ではなく再設定を使う |

### 設定済みのパスワードを忘れた場合

1. 園が本人確認し、対象保護者の「認証管理」を開きます。
2. 「パスワード再設定」の「再設定理由」を入力して、「再設定コードを発行」を押します。
3. 6文字のコードと `施設URL/parent-portal/reset` を本人へ渡します。
4. 本人がコードを確認し、新しいパスワードを2回入力して「再設定する」を押します。
5. 登録メールアドレスと新しいパスワードでログインします。再設定により既存のログインセッションとプッシュ通知登録は無効になります。

初期登録未完了・停止中の保護者には、通常の再設定コードを発行できません。停止から再開する場合は、園が再開を確認して台帳の状態を「有効」に戻し、第6章の「初期設定・利用再開」を行います。

登録後にメールアドレスを変える場合は、管理者の認証管理にある「登録メールとログインIDを変更」を使用します。通常の連絡先編集だけでログインIDも変わったとは判断しないでください。登録途中のメール変更は、修正した宛先で再招待します。

## 9. 保護者へ渡す案内文

施設URL・連絡先を埋めて、必要な方だけを使用します。パスワードは本人に設定してもらいます。

### メール招待の場合

> 保護者ポータルの登録案内を、園へお届けいただいたメールアドレスに送ります。最初のメールから、園に登録した保護者・園児の氏名（カナまたは英字）と園児の生年月日を入力してください。園の確認後、パスワード設定用のメールをもう一度お送りします。各メールのリンクは発行から24時間以内に開き、開いた後は15分以内に入力してください。設定後のログインIDは登録メールアドレスです。メール未着や入力不一致の場合は、園の担当者［連絡先］へご連絡ください。

### コード交付の場合

> 園から個別にお渡しする6文字のコードを、［施設URL］/parent-portal/activate に入力してください。コードは発行から30分以内、コード確認後のパスワード設定は15分以内に行ってください。初回設定画面の送信ボタンは現在「再設定する」と表示されます。設定後は［施設URL］/parent-portal/login から、登録メールアドレスとご自身で設定したパスワードでログインしてください。
