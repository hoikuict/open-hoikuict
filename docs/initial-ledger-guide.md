# 初期台帳のExcel準備・登録

手元の名簿や緊急連絡表を、オープン保育ICTの初期台帳へ移す手順です。園児台帳の管理権限が必要です。[利用開始マニュアル](start-manual.md)の手順3・4を詳しく説明します。

## 1. 元表と入力用Excelを分けて用意する

1. 元の名簿・緊急連絡表を保管し、作業用コピーを作ります。
2. アプリの「インポート・エクスポート」→「初期台帳をExcelから登録」を開きます。
3. 「入力用Excelをダウンロード」を押します。
4. テンプレートの「記入例」「項目の説明」を確認します。
5. 「入力用」の5行目から、値のみを貼り付けます。4行目の見出しや列の順番は変えません。

取り込み用Excelは38列、入力欄は200人分です。必要な場合は入力行を追加でき、1回の上限は1000人・20MBです。読み込むのは「入力用」だけです。「記入例」や別シートに残した原本は取り込みません。

## 2. 園児1人につき1行へ整理する

元表で1行に複数のきょうだいが載っている場合は、園児ごとに行を分けます。その子が別の行にも載っている場合は、氏名・氏名カナ・生年月日と原本を照合し、同じ子を二重に登録しないよう整理します。

同じ氏名だけで同一人物と決めたり、同じ姓だけで同じ家庭にまとめたりしないでください。氏名の表記や生年月日が食い違う場合は、原本で確認する箇所として残します。

以下はすべて架空の例です。

| きょうだいグループ | 姓 | 名 | 姓カナ | 名カナ | 生年月日 | 入園日 |
| --- | --- | --- | --- | --- | --- | --- |
| A | 見本 | 花 | ミホン | ハナ | 2022/04/10 | 2026/04/01 |
| A | 見本 | 空 | ミホン | ソラ | 2024/05/20 | 2026/04/01 |
| 空欄 | 見本 | 光 | ミホン | ヒカリ | 2021/07/01 | 2026/04/01 |

上の2人は同じ家庭、3人目は同姓の別家庭です。グループ欄は任意の文字でよく、空欄は園児ごとに別家庭として扱います。園児整理番号・家庭整理番号・家庭名は読み込み後に自動設定されます。

## 3. 元表の項目を合わせる

| 元表の項目 | 初期台帳への入力 |
| --- | --- |
| 園児の氏名 | 「姓」「名」に分けます。複数語や区切りが曖昧な氏名は本人情報で確認します。 |
| 園児のふりがな | カタカナにそろえ、「姓カナ」「名カナ」に分けます。読みは推測で変更しません。 |
| 生年月日 | 西暦の日付として入力します。数字の連続や文字列が正しい日付になっているか確認します。 |
| 入園日 | 原本で確認して個別に入力します。元表にない場合は準備中は空欄にし、登録前に補います。 |
| クラス | 「クラス名」へ入力します。同じクラスは同じ表記にそろえます。 |
| 家庭の住所・電話 | 「家庭住所」「家庭電話番号」へ入力します。園児固有の住所・電話がある場合は園児の欄に入力します。 |
| 保護者の氏名・ふりがな | 保護者①②それぞれの姓・名・姓カナ・名カナへ分けます。 |
| 保護者の携帯・メール | 対応する保護者①②の電話番号・メールアドレスへ入力します。 |
| 勤務先・部署 | 部署専用の列はないため、必要に応じ「勤務先」に `勤務先名／部署名` の形でまとめます。 |
| 勤務先住所・電話 | 対応する保護者の勤務先住所・勤務先電話番号へ入力します。 |

必須項目は**姓・名・姓カナ・名カナ・生年月日・入園日・在園状態**です。在園状態は「在園」「卒園」「退園」から選びます。卒園・退園の場合は退園日も確認してください。

保護者の連絡先だけがあり氏名がない場合は、姓・名の入力が必要です。存在しない保護者の欄は空欄にします。

## 4. 電話番号と家庭内の不一致を確認する

電話番号の列は、貼り付ける前にExcelの表示形式を**文字列**にします。先頭の0がすでに失われていたら、表示形式を変えるだけでは戻りません。原本で正しい番号を確認してください。

同じきょうだいグループでは、家庭住所・家庭電話番号・保護者①②の情報を同じ内容にそろえます。番地が `1-2-3` と `1-2-13` のように異なる場合は、どちらかを推測で採用せず、正しい住所を確認して全員分を修正します。

確認が必要な箇所は、取り込み用の行番号、項目名、原本の値、確認する内容を別シートや作業メモに残すと修正しやすくなります。確認メモはアプリが自動作成するものではありません。

## 5. 取り込み対象外の情報を保管する

初期台帳に専用欄がない項目は、列を追加して入力用へ混ぜず、元表や別シートに残します。追加の緊急連絡先、勤務日・勤務時間・通勤時間、血液型・平熱、同意欄、自由記入の備考などが該当します。

初期台帳の読み込みだけでこれらの情報は登録されません。登録後に対応する台帳画面や[CSVの取り込み手順](family-guardian-csv-guide.md)で扱う項目を確認します。

## 6. 読み込んで、エラーと家庭を確認する

「読み込んで確認する」を押し、園児・家庭・クラスの件数を元表と照合します。「修正が必要です」の行番号・項目を確認し、画面で修正したら「編集内容を再確認する」を押します。

| 表示・状況 | 確認すること |
| --- | --- |
| 必須項目が空欄 | 入園日や氏名など、指摘された項目を確認して入力します。 |
| 保護者の姓・名が必要 | 電話・メール等だけが残っていないか確認し、正しい保護者名を入力します。 |
| 同じきょうだいグループで内容が異なる | 家庭と保護者の住所・電話・メール等を原本で確認し、そろえます。 |
| 数値の電話番号 | 原本で先頭の0を確認し、文字列として入力し直します。 |
| 同じ氏名カナ・生年月日がある | 重複なのか別園児なのかを確認します。既存台帳がある場合はそちらを確認します。 |
| 数式・見出しのエラー | 正しいテンプレートの「入力用」へ、値のみ貼り付け直します。 |

「家庭のまとめ方」では、同姓の別家庭が混ざっていないか、きょうだいが別家庭になっていないか、保護者①②が正しいかを確認します。クラス名が既存と一致すれば登録済みクラスを使用し、新しいクラスだけ作成します。

画面から行を追加したり、今回の取り込みから除外したりできます。これらの操作は確定前の取り込み内容に対して行うもので、登録済み園児を削除する操作ではありません。

## 7. 最終確認して登録する

1. エラーを解消し、「登録内容の最終確認へ」を押します。
2. 人数・家庭のまとまり・確認事項のチェックを入れます。
3. 「台帳に登録する」を押します。
4. 完了画面から園児台帳・家庭台帳を開きます。

**「台帳に登録する」を押した時点で保存**します。それまでは「修正に戻る」「今回の読み込みを取り消す」でやり直せます。途中で登録に失敗した場合は、今回の登録全体が取り消されます。

画面での修正は元のExcelに書き戻されません。必要に応じて、確定した内容を園の保管用ファイルにも反映してください。

同じ内容を再取り込みしても重複登録はしません。登録済み園児の更新用には使えないため、登録後の修正や既存家庭への弟妹の追加は台帳画面から行います。

## 8. 保護者の利用開始へ進む

初期台帳の登録ではログイン用アカウント、閲覧権限、招待メールは作成しません。台帳を確認した後、[アカウントと利用開始](accounts.md)へ進んでください。
