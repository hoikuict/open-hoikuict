# 日々の業務

職員は `/staff/login` からログインし、職員ホームを入口にします。表示できる情報と操作できる範囲は、ロール、担当クラス、業務別権限によって変わります。画面ごとのURLは[画面一覧](screen-transition-list.md)を参照してください。

## 朝の連絡と登園を確認する

1. **職員ホーム**で今日の予定、担当クラスの出席サマリー、要確認を見ます。一般職員も担当／全クラスのサマリーを切り替えられますが、園児別明細や編集の権限は変わりません。
2. **日次連絡**で欠席、体調、睡眠、食事、服薬などの保護者連絡を確認します。
3. **登降園管理**で打刻を確認し、**出欠確認**で実際の在園状況と照合します。
4. 連絡と打刻が一致しない園児を確認し、必要な場合に保護者へ確認を依頼します。通知の条件は[保護者通知](notifications.md)にまとめています。

登園・降園の受付に共用端末を使う場合は、[専用キオスク](chromebook-guardian-kiosk.md)を設定します。

## お迎え予定と誤打刻を訂正する

登降園管理の「お迎え予定を変更」から時刻・予定者を編集できます。変更者・日時・変更前後を履歴に残します。別の職員が先に更新した場合は、画面を開き直して最新値を確認します。

誤った打刻は、編集可能な職員が理由を入力し、「降園のみ」または「登園・降園・お迎え予定」を取り消します。元の打刻と料金を監査履歴に残します。

!!! note "料金が確定している場合"
    確定・調整・対象外・請求転送済みの延長料金がある打刻は取消を拒否します。請求状態を確認し、[料金・請求転送仕様](extended-care-billing-transfer-spec.md)に沿って処理します。未確定料金は取消時に削除し、次の降園時に再計算します。

詳しい条件は[9月10日の改善](spec-improvements-2026-09-10.md)と[9月11日の変更](spec-improvements-2026-09-11.md)を参照してください。

## 健康・保育の記録を残す

| 記録したいもの | 入口 | 関連仕様 |
| --- | --- | --- |
| 健康プロフィール、アレルギー、健診 | 健康管理、園児詳細の健康サマリー | [健康管理](health-record-spec-review.md) |
| 観察や子どもの育ち | 園児詳細の「子どもの記録」 | [児童記録](child-records-spec.md) |
| 児童票 | 園児詳細の児童票、児童票進捗一覧 | [児童記録](child-records-spec.md) |
| 年案・月案・週案・日案 | 指導計画 `/plans/` | [保育計画の仕様一覧](specifications.md#plans) |
| 園内の知見、行事の振り返り | 園内記録、ハイライト、年度継続記録 | [画面一覧](screen-transition-list.md) |

日案はカレンダーから作成状況を確認し、詳細画面で振り返りや実施変更を扱います。文例が空の場合は、入力内容だけでなく[文例DBの配置](architecture.md)も確認します。

## 職員間で共有・確認する

カレンダー、職員ルーム、議事録、職員アンケートを使って共有します。職員ホームの「今日の予定」は閲覧権限のある接続カレンダーの確定予定を表示し、カレンダー画面で表示をOFFにした予定も含みます。

管理者へファイルや本文の確認を依頼するときは **文書の確認依頼** `/document-reviews/` を使います。Word・PDF・Excel・画像・テキストなどを添付でき、上限は5件、各10MB、合計20MBです。提出者と管理者が閲覧でき、提出後の修正版は新しい依頼にします。

## 保護者の申請を確認する

管理者はホームの承認待ちから、保護者の初回登録と文書の確認依頼を確認します。利用開始後の園児情報変更は「プロフィール変更申請」で確認・承認します。

共通QRによる登録では承認先の園児・保護者を必ず選択します。きょうだいの閲覧許可は保護者アカウントで明示的に指定してください。[アカウントガイド](accounts.md)に登録経路をまとめています。

## 月末の料金・請求を確認する

1. 園児別の保育認定と適用期間、標準時間・短時間の料金ルールを確認します。
2. 延長料金の月次画面で「料金未算出」の理由や打刻不足を確認します。
3. 必要な月を再計算し、確定・調整・対象外を整理します。設定変更だけでは過去の料金は再計算されません。
4. [請求転送](extended-care-billing-transfer-spec.md)のプレビューで対象と競合を確認して転送します。
5. 請求担当者が園児別請求と口座情報を確認し、必要な出力を行います。

口座情報の表示・編集には専用権限が必要です。詳細は[職員権限・請求口座](staff-permissions-and-billing-accounts-spec.md)を参照してください。
