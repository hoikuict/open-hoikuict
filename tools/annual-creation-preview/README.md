## 要望と確認済みの内容

- 年間指導計画のクラス・担任を作成時のものにする。
- 担任は作成時のクラスに登録された担任を初期表示し、必要なら編集できる。ユーザー回答「登録された担任を表示」。
- 年間指導計画反省を記入できるようにする。ユーザー回答「反省欄は空欄から始める」。
- 取り込み済みの反省は参考資料として残し、今回の反省欄へは自動コピーしない。
- 追加要望：年間指導計画反省と日案の反省は、入力後に承認確認へ進み、管理者の通知に載るようにする。

## モックにした解釈・提案

- 作成とは年案の初回保存。選択したクラス名・担任名を文書に保持し、その後登録情報が変わっても保存した年案の表示を自動で置き換えない。担任名の手修正は可能。
- 担任登録がない場合は空欄にし、手入力して保存できる。元の年案の担任名を初期値にしない。
- 既存の保存済み年案は保持する。一括で過去の担任やクラス名を推測して書き換えない。
- 反省は年度・クラスごとに4期×2欄。乳児は「生活・遊び」、幼児は「基本的事項・五領域」。期の表示は既存の各クラスの反省様式を踏襲。2歳児の反省は年案と期区分が異なり、5歳児原本の3期の月は記載がないため、推測で補わない。
- 年案が未保存でも、反省の「下書き保存」「承認確認へ進む」を押せる。初回は入力中の年案と反省の下書きを保存する。保存済みの年案では、反省のみを保存する。「承認確認へ進む」で選択した期の内容確認画面へ移動し、「管理者へ承認を依頼」で確定する。年案本文の承認状態は保持する。
- 年間反省の承認単位は期ごとを提案してモック化した（最終モックの「OK」で合意）。日案はその日ごと。入力・下書き保存のみでは管理者へ通知しない。
- 管理者の職員ポータル「すべての承認待ち」と「計画文書・児童票の通知」に依頼を表示。通知を開くと依頼した版の反省が表示され、承認・差戻しができる。既読になっても承認待ち件数は減らない。
- 承認依頼中は対象の反省を閲覧専用にする。依頼を取り下げると修正でき、承認待ちから除く。差戻し理由は必須で、入力した職員に結果を通知し、修正して再依頼できる。
- 承認済みの反省は「修正して再依頼する」から修正する。新たな依頼は新しい版として扱い、前の依頼や承認内容を上書きしない。年案の別の期は独立して記入できる。
- 年案の保存で入力中の反省を消さず、反省の保存で入力中の年案本文を消さない。反省の「入力を戻す」は確認後、最後に保存した反省へ戻す。承認確認から「入力へ戻る」を押しても内容を保持する。
- 年度・クラスを切り替えるときは未保存の入力を確認する。翌年度の反省は空欄から始める。
- 保存エラー時は入力を保持する。年案本文の編集・開始目安・確認・差分・元に戻す等の既存操作を残す。

これらの操作・保存タイミングは修正版モックで合意した。反省のアクセス権・競合検出・改訂記録・通知先は実装記録に記載し、独立したDBと実ルーターで検証した。現行の計画文書の承認通知は `plan_docs/services/review_notifications.py`、職員ポータルは `templates/portal/index.html` が基準。
