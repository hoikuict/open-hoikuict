# GitHub取得式インストーラーの操作モック

2026-09-23に作成。ユーザーが試用し、「この流れで実装を進める」と回答済み。仕様は [変更記録](../../docs/github-installer-2026-09-23.md)。

既存の `beta_setup/ui` の見た目と全入力項目を保持し、最新版の確認、ダウンロード、通信失敗・再試行、配布未公開、導入アプリ非対応、確認後の版変更を追加した。

上部で未入力・一部入力・入力済み・各エラー・導入済みを切り替える。処理はすべて架空。CSPで通信とフォーム送信を禁止し、入力はページのメモリーだけで保持する。

```powershell
venv/Scripts/python.exe -m http.server 18847 --bind 127.0.0.1 --directory tools/github-installer-preview
```

ブラウザーで `http://127.0.0.1:18847/` を開く。本番DB、GitHubのダウンロード、アカウント作成、保存・削除処理を呼び出さない。
