# 日案の印刷余白：確認用モック

2026-10-11。状態：内部罫線を除いたモックをユーザーが承認し、アプリ本体への実装・検証が完了。その後の依頼により本番配備・完了確認も実施済み。

## 要望と解釈

- 要望：添付された日案のPDFを基に、無駄な余白をなくして1ページに収めたい。
- 解釈：日案詳細画面の印刷レイアウトを調整する。本文を短縮したり、行を削除したりせず、表の改行・字下げと各領域の内側余白を整理する。
- 合意した配置：A4縦、用紙余白8mm、本文・表10pt、4列は維持。ねらい・内容は見出しと本文を横に並べる。未入力の振り返りは「未入力」と表示し、入力済みなら全文と最終提出日時を印刷する。実施変更も残す。
- 追加指示「内部の罫線はなくていい」に合わせ、表内の縦線・横線を除いた。外枠と列見出しの下の区切り線を残し、4列と行ごとの内容の対応を維持した。
- 長文の扱い：切り捨て・隠し込み・自動縮小は行わず、長文は必要なページ数になる。極端に長い本文や多数の実施変更まで一律1枚にする仕様ではない。

保存・提出・遷移は模擬動作。全データは架空で、DB・本番・外部への接続なし。リロードで入力内容は消える。ブラウザー印刷時はA4縦・倍率100%・ヘッダーとフッターをオフにする。
