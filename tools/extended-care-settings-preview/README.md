# 延長保育料金設定の操作モック

2026-10-04。本番版 `744d05fc95afedfffc79c4f93739b08cb38b396e` の延長料金設定画面を基準にした確認用の静的画面。
本番アプリ、DB、認証、メール、請求送信には接続しない。保存はブラウザーのメモリ内のみで、再読み込みすると初期化する。

## 起動

```powershell
python -m http.server 8896 --bind 127.0.0.1 --directory tools/extended-care-settings-preview
```

`http://127.0.0.1:8896/` を開く。

## 要望

- 保育標準時間・保育短時間を別の枠にする。
- 前延長・あと延長の使用／不使用を区分ごとに設定する。
- 開始・終了時刻を明示し、18〜19時・19〜20時などの複数時間帯に対応する。

## このモックで試せること

- 未入力、入力済み、一部入力、入力エラーの切替。次回保存だけのエラーも指定できる。
- 2区分の独立編集、時間帯追加・削除・削除を戻す、使用しない側を閉じて再度開いた場合の入力保持。
- 時間ごとの課金／時間帯ごと定額、猶予、日別上限を含む保存前の料金試算。
- 保存内容の確認と、このタブ内への保存。確認を閉じると保存せず入力へ戻る。「変更を戻す」は保存前の入力だけを戻す。
- 計算モード、請求連携、従来ルールの既存入力項目も別枠に残し、画面全体の長さを確認できる。
- 保存した設定で架空の3日分の再計算対象を確認。実績データや請求は変更しない。

## 解釈・提案

区分は枠に固定し、ルール名から推測しない。通常保育時間 → 前延長 → あと延長 → 適用期間・ルール名・上限 → 確認して保存、の順。
前後とも使用しない設定も有効な設定として保存でき、未設定と区別する。
通常保育・料金ルールの保存は区分ごと。計算モードと請求連携はそれぞれ別に保存する。
適用開始日・終了日、有効フラグ、通常保育時間、前後の猶予、課金単位、単価、日別上限、従来延長開始時刻、請求費目、明細テンプレートを保持する。

## 未確定事項と試算の仮定

- 前後各1回、通常保育との境界で猶予を適用する。途中の区切りでは適用し直さない。
- 料金は利用した時間帯ごとに切り上げて合算する。時間帯定額は1分以上利用したら1回分。
- 19:00ちょうどに降園した場合、19:00からの時間帯には課金しない。
- 重複と途中の空白は保存エラー。意図した無料部分は0円の時間帯で表現する。
- 設定時間帯の外、使用しない前後延長での利用は合計を未確定として表示する。
- 同日内のみ試算する。日付をまたぐ延長、時間帯端の扱い、施設ごとの課金方式は本実装前に確認する。
- 切替前ルールの引継ぎ、複数の適用期間の履歴編集、過去料金の差額確認は次の仕様確認事項。
- 本モックは標準・短時間の両方を利用する架空施設のため、計算モード保存時に両区分の保存済み設定を検証する。
