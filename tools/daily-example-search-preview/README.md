## 要望と解釈

要望は「検索で年齢や月を選択しないケースも追加」。年齢・月をそれぞれ「すべて」にでき、年齢だけ／月だけ／両方なしで検索できる、と解釈した。

- 年齢「すべて」：年齢による絞り込みを外す。
- 月「すべて」：月による絞り込みを外す。
- 両方「すべて」：年齢・月では絞り込まない。キーワードのみの検索も可能。
- 未指定を選んだ後は、クラス・対象日による自動補完で条件を戻さない。
- 検索条件と、下書きを保存するための必須の年齢・対象日は別扱い。検索だけでは下書きを変更しない。
- 候補のコピーでは、その候補の年齢を下書きへ設定する。検索条件は維持する。
- 詳細の開閉、既存入力欄、模擬保存、未入力・一部入力・入力済み・エラーの確認操作を維持する。

この「すべて」の使い方と、候補コピー後も検索条件を維持する動きで合意。初期条件は現在の0歳児・10月を維持して試せるようにした。実装記録は `docs/daily-example-search-implementation-2026-10-11.md`（リポジトリルート基準）。
