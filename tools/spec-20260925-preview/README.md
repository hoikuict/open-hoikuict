## 開く

- モック全体：<http://127.0.0.1:8886/>
- 端末画面だけ：<http://127.0.0.1:8886/?terminal=1#kiosk>
- 名前一覧：<http://127.0.0.1:8886/#roster>
- 子どもの記録：<http://127.0.0.1:8886/#records/1>

停止している場合、リポジトリのルートで起動する。

```powershell
venv/Scripts/python.exe -m http.server 8886 --bind 127.0.0.1 --directory tools/spec-20260925-preview
```

ループバックでのみ提供する。本番DB・API・通知処理に接続しない。
CSPの `connect-src 'none'` と `form-action 'none'` で通信・フォーム送信を禁止。
架空100人・架空職員3人。保存はタブ内のメモリのみで、再読み込みすると初期化する。
職員切替は公開範囲の見え方を確認するUI再現であり、実際の認証・権限制御ではない。

## 試す順番

1. **キオスク**：初期表示は「くるみ」20人。名前欄に出欠状態は表示しない。
   現行の2列／4列のレスポンシブ配置を保ち、名前の表示サイズを調整。
   「端末画面だけを開く」で試用用の上部UIを外して確認できる。
   試用設定の40人に切り替えると、通常のスクロールで全員を表示する。
   クラス・子どもの選択、登園、お迎え時刻／人／補食、確認・修正・取消、降園も操作できる。
2. **名前一覧**：名前を押し、「メモを書く」または「記録を見る」へ。
   既存の時刻・目視確認・家庭連絡・アラーム、出欠／連絡への導線も保持。
3. **メモ**：「自分だけ」「みんなで共有」を選んで保存。
   観察日、子どもの姿、関わり、振り返り、次の視点、家庭連携、記録区分、領域・視点を省略しない。
   全項目を表示する「しっかり」相当で画面の長さを確認する。
   園独自項目は上部試用設定で見本を表示。管理者では取扱区分と限定共有先も設定できる。
4. **職員切替**：上部「試用設定」から別職員・管理者へ変更し、表示範囲を確認。
   青葉はるの初期データに本人だけ・別職員の個人メモ・全体共有・管理者限定の見本がある。
5. **出欠確認**：青葉はるなど未選択の子の状態を選ぶ。理由ウインドウは表示されず反映。
   続けて別の状態を選ぶと理由ウインドウが開く。「誤入力」「変更連絡あり」または自由入力で理由を指定。
   「理由を記録して確定」で反映し、取消・Escapeなら元の状態を維持する。
   変更理由の確定後は詳細欄を閉じた状態にする。自動では開かず、「詳細」ボタンを押した場合だけ表示する。
6. **入力状態**：「未入力」「入力済み」「一部入力」「保存エラー」を切り替える。
   未入力では出欠が全員未選択。初期の一部入力では選択済み／未選択が混在。
   保存エラーから解除すると入力はそのまま保持される。

## モック上の仮置き

以下は確認対象の提案であり、確定仕様として扱わない。画面の「合意事項・仮置き」にも明記。

- メモの初期値は「自分だけ」。管理者も他人の個人メモは閲覧できない。
- 全体共有の閲覧は職員全員。訂正・無効化は作成者と管理者。
- 限定共有は管理者が職員を個別指定。作成者・管理者も閲覧可能。
- 記録の訂正・公開範囲変更は、既存の訂正理由入力を維持する。無効化は理由と履歴を保持。
- 理由ボタンは理由の入力のみ。確定ボタンで出欠を反映。
- 同じ出欠状態の再選択は変更扱いにしない。
- 初回「不明」でもウインドウ・通知は出さない。変更後が「不明」の場合の既存通知選択欄は維持。
- 関連画面の保護者連絡・閉園設定は今回の主対象ではなく、導線・既存入力を試すため残している。
