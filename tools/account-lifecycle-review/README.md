# アカウントの利用停止・再開：確認用モック

基準は配備版 `15b13a9dd1eb6ae1b4d171186cb12c1dcc33326c`。停止・再開を認証管理へまとめる変更案で、業務アプリの実装ではありません。

起動例（リポジトリのルートから）：

```powershell
venv/Scripts/python.exe -m http.server 8876 --bind 127.0.0.1 --directory tools/account-lifecycle-review
```

ブラウザーで `http://127.0.0.1:8876/` を開きます。データはすべて架空。外部通信・本番接続・実メール送信はなく、再読み込みで初期化します。

## 試す操作

1. 最初の「一時停止中」で再開理由を入力し、確認後に再開。現在のパスワードを維持して利用中になります。
2. 「保護者の再ログインを試す」で閲覧可否を確認。一覧・保護者情報にも同じ利用状態が出ます。
3. 利用停止、理由の修正、確定前の取消を試します。
4. 確認用の上部で、未入力・入力済み・一部入力・保存エラーを切り替えます。未入力は新規の操作欄、既存プロフィールは保存済みの見本を表示します。一部入力はメール変更の確認欄などが未入力です。
5. 「再設定が必要な停止」では再設定を伴う再開案内を試します。設定完了の再現ボタンは確認用の上部にあり、業務画面とは区別しています。
6. 「台帳担当」では利用停止・再開が操作できないこと、従来の不整合状態・未登録・申請確認待ち・アドレス削除済みを確認します。
7. 「他の一本化候補を見る」で、今回の対象と未確定候補を確認します。

既存の保護者情報入力項目、100人中98人への許可、認証管理の初回案内・メール／ログインID変更・配送履歴・提出内容28項目・承認入力・パスワード再設定を用意しています。入力理由と確認の往復、保存失敗時の保持、プロフィール編集のキャンセルも試せます。
