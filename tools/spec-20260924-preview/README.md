# 2026年9月24日変更の確認用モック

出欠・保護者連絡・保護者キオスクの操作を架空データで確認する独立した静的モックです。業務アプリの実装や配備は変更しません。

## 一覧性の調整

追加の要望に合わせ、名前一覧と出欠確認を詰めた表示に変更しました。

- 出欠確認は初期表示を全クラス・全員とし、在園・降園・お休み・未登園をすべて表示。絞った後も「全員を表示」で戻せます。
- 出欠確認はPCで1人1行。現在の状態、登園と降園の両時刻、保護者連絡、目視確認ボタンを横並びにしました。
- 名前一覧は4区分を維持して、名前を詰めて横に並べます。時刻は名前を押した詳細で確認できます。
- 名前一覧の文字サイズは13px、出欠確認の名前は13pxを基本とし、大きな余白と繰り返しの説明を削減。スマートフォンでは折り返し、タッチ端末のボタンは40px以上を確保します。
- 上部の試用設定は折りたたみました。入力状態・入力方式・画面幅の切替は引き続き使用できます。
- キオスクの名前選択にも全状態の子を表示し、現在の状態を添えました。
- トップの6種類の人数表示、既存の入力項目、理由・訂正者の記録は維持しています。

同じブラウザー幅885pxで、名前一覧の本文全体は4,644pxから1,087pxに短縮。100人と24区分（6クラス×4状態）の表示を維持しています。出欠確認の閉じた行は1人43pxです。

## 開く

起動中のURL：<http://127.0.0.1:8884/>

停止している場合は、リポジトリのルートで次を実行します。

```powershell
venv/Scripts/python.exe -m http.server 8884 --bind 127.0.0.1 --directory tools/spec-20260924-preview
```

外部通信・実DB接続・実際の公開や通知はありません。`connect-src 'none'` と `form-action 'none'` を指定しています。データはこのタブのメモリだけに保持し、再読み込みでリセットします。園児100人、職員、保護者、連絡内容はすべて架空です。

## 試す順番

1. **子どもの名前一覧**：クラス別の在園・降園・お休み・未登園、名前検索、名前を押した詳細、出欠確認への移動を確認します。
2. **トップ**：既存の在籍・登園・在園中・降園・欠席・未登園の人数表示を維持します。名前一覧へは別リンクで移動します。
3. **出欠確認**：きいちごの「青葉 はる」の「出席」を押し、理由なしで保存を試した後、理由を入力して確定します。訂正者・理由・変更前後・日時を履歴に記録し、出欠確認に留まります。電話・口頭連絡受付、取消、誤打刻取消も操作できます。
4. **保護者連絡**：一覧から園児を開きます。既存の保護者連絡詳細を省略せずに表示し、園からの連絡の既存5項目を入力します。「園からの連絡を入力」で入力欄まで移動できます。
5. **入力方式比較**：上部の試用設定で「ボタンで選ぶ」「従来のプルダウン」を切り替えます。内容は保持します。体温は整数と小数の両方を選びます。
6. **日付移動**：同じ子どもの前日・翌日へ移動します。未保存なら下書き保存・破棄・入力に戻るを選びます。下書きは未送信のままです。「この子の連絡履歴」で日別に確認できます。
7. **保護者キオスク**：予定時刻・お迎えの人・補食を入力し、確認・修正・登録・取消を試します。クラスと名前の選択、登園・降園の場面にも切り替えられます。
8. **閉園時間の設定**：19:30などに変更し、時・分・1分単位の選択肢が変わることを確認します。設定変更前の範囲外時刻が残っていても登録できません。

試用設定は業務画面と分けて上部に置いています。未入力・入力済み・一部入力・保存エラーを切り替えられます。エラーから別の状態に切り替える場合は、再試行できるよう入力内容を保持します。ダイアログ内の失敗は、その中の「試用操作」で解除できます。

PC・タブレット・スマートフォンの幅に切り替え可能です。実際にブラウザーの幅を狭くしても表示が変わります。

## 合意済み

- 訂正理由と訂正者を必ず記録する。訂正後は出欠確認画面に留まる。
- トップの人数表示は今のまま残す。子どもの名前を確認する別ページを作る。
- 名前一覧には在園・降園・お休み・未登園が必要。
- 閉園時間以降のボタンは非表示。設定可能とし、範囲外の入力を受け付けない。
- キオスクの全画面終了ボタンを目立たなくする。
- 園からの連絡は既存項目を維持し、ストレスなく早く入力できるUIを試す。
- 同じ子どもの日付を移動する。未送信を明示する。

## モックで仮置きしたこと

- 訂正者はログイン職員の固定表示。訂正履歴には日時と変更前後も表示。
- 閉園19:00の例。閉園時刻ちょうどを含めて除外。曜日別設定なし。現在時刻が閉園以降の場合も受付終了として表示。
- 選択済みの時刻が設定変更で範囲外になった場合は、自動変更せず選び直しを求める。
- 公開前の確認画面を追加。未保存の移動は選択式とする。
- 公開済みの連絡を修正して下書き保存した場合、公開済み内容を保持し「未送信の変更あり」と表示。
- 連絡履歴の表、各クラスの4区分、入力方式Aは配置・操作の比較案。
- 全画面終了は配置と操作後の案内を再現。実際の全画面APIは使わない。

未確定事項を本実装の確定仕様とは扱いません。公開取消の機能は対象外です。
