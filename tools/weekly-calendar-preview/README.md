ユーザーの修正依頼を受け、乳児用を「週・期間／ねらい」「活動」「配慮・援助すること／準備」「評価・反省」の4列に修正した。期間とねらいは同じセルに置き、配慮援助と準備は改行可能な一つの入力欄で保存する。参考例も同じ区分で表示・コピーする。幼児用は週全体のねらいと反省、月～土の活動・援助配慮・準備をそれぞれの欄に保持する。

## こちらの解釈と仮仕様

- 参考例を年齢・月・キーワードで探し、詳細を開いてから下書きへコピーする。開閉・検索だけでは下書きを変更しない。
- 確認済みの年齢区分に合わせ、0～2歳は週を縦に並べる乳児様式、3～5歳は曜日ごとの幼児様式を自動表示する。
- 現行週案フォームの13項目をすべて残す。原票のねらい・援助・準備・反省を追加する。
- コピーするのは計画の内容だけ。作成者・クラス・対象期間・過去の評価反省・承認印はコピーしない。
- 入力中は未保存。保存ボタンで画面内メモリーに保存する。戻るとき、入力状態切替、候補の上書きには取消可能な確認を出す。年齢による様式切替は週全体・曜日別の入力を両方保持する。
- 月案カレンダーは年度の12か月、週案カレンダーは選択月に交差する週を表示。クラスと期間で記録を分離する。月をまたぐ週は同じ開始日で識別する。
- 月案カレンダーからは、新しい「帳票から月案をつくる」画面を開く。選択した月・クラス・年齢を引き継ぐ。旧月案作成フォームは使わない。
- 月案は0～2歳の個人別帳票と3～5歳の集団帳票を表示する。現行帳票の共通欄、園児別ページ、各領域、食育、行事欄、過去3か月表示を保持する。
- 月案の保存内容は月・クラス・年齢で分離し、保存後はカレンダーの作成状況と再表示に反映する。参考候補・過去の月案は架空データ。未保存で戻る場合は、取消可能な確認を出す。
- 承認済みの見本は閲覧のみ。承認や通知の仕組みはここで新設しない。
- 保存済みへの修正は「保存」で反映。「保存した内容に戻す」は保存後の変更だけを取り消す。
- 「取消」は未保存の変更を破棄してカレンダーへ戻る。記録削除や業務上の承認取下げは扱わない。
- 未入力・一部入力・入力済み・入力エラー、候補なし・読込エラー、保存失敗を試せる。

## 起動

リポジトリルートで `python tools/build_weekly_calendar_preview.py` を実行して生成する。
`python -m http.server 8890 --bind 127.0.0.1 --directory tools/weekly-calendar-preview`
ブラウザーで http://127.0.0.1:8890/?v=weekly-format#weekly を開く。「週案を作成」で帳票を開き、基本情報の年齢を変更すると年齢別の形式を確認できる。月案から確認する場合は http://127.0.0.1:8890/?v=monthly-sheet#monthly を開く。再読込で見本データに戻る。

モック試用・合意後に本実装へ進む。配備は別途の依頼に従う。
