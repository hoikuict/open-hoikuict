# 月案の編集画面からレビュー依頼するモック

月案だけを試す確認画面。仕様の根拠・合意状態は `docs/spec-decisions.md` のSD-056、動作案と未確認事項は `docs/monthly-review-button-preview-2026-11-15.md`。

基準は2026-11-15 08:40 JST配備版 `0e1249f301b3257ae9afe0b76f47602bcd2cbe4f`。編集画面6件＋詳細画面6件、架空の8園児。元の入力項目と月案レンダラーを保持し、レビュー依頼を保存の隣へ追加した。

- レビュー時は計画欄を必須とし、未記入がある間は止める。評価・反省と行事・活動は除外する。チェック条件は利用者回答で合意済み。
- 理由のリンクから別ページも含む対象欄へ移動し、修正後に再度依頼する。
- 入力済みなら現在の内容を保存して依頼し、詳細へ進む案。詳細側でも未記入を検査する。取り下げ→修正も試せる。
- 下書き保存は途中でも可能。担任名必須は現行どおり。

起動：`venv/Scripts/python.exe -m http.server 8098 --bind 127.0.0.1 --directory tools/monthly-review-preview`

入口：`http://127.0.0.1:8098/edit-0.html`。年齢は業務画面の年齢クラスで切り替える。上の「試す状態」は確認用で、本番への追加項目ではない。

再生成：`venv/Scripts/python.exe tools/monthly-review-preview/build.py`

静的検証：`venv/Scripts/python.exe tools/monthly-review-preview/verify.py`

`build.py` は基準コミットとクリーンな作業ツリーを検査し、隔離メモリーDBだけでテンプレートを描画する。画面は全通信と通常のフォーム送信をCSPで禁止。仮保存はタブ内のsessionStorageだけを使用し、状態を入れ直すと対象年齢の仮保存を初期化する。本番DB・通知へ接続しない。

対象は2026年11月の架空例。別期間・別クラスの実データ、出力、AI生成、版履歴の更新、同時編集の実通信はこの試用の対象外。既存の入力欄は残す。実装済み・配備済みの業務画面として扱わない。

検証は6年齢の依頼→取り下げ→修正、別ページの未記入、除外欄の空欄許容、本文空欄の下書き、担任名、通信エラー・再試行、0歳と5歳の3画面幅。静的な元入力欄・隔離設定は `static-verification.json`、ブラウザー操作は `browser-verification.json`。再生成時は証跡を別途更新する。
