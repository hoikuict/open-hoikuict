# 園児別・月間の登降園補記モック

2026-10-04。仕様確認用の静的モック。実装・配備用ではない。

## 要望

- 月末などに登園・降園の未打刻を修正したい。
- 園児個人を選び、園児Aの10月など、1か月の記録を一括表示して抜けを修正したい。

## 解釈と試用する提案

- 園児別は全日表示を初期状態とし、欠席・利用予定なし・両方未打刻の日も含む。
- クラス・園児・月の切替、前後の園児への移動、漏れ・要確認への絞り込み。
- 全クラス／クラスの打刻漏れ一覧からも、同じ日別の編集を利用できる。
- 出席確認か片方の打刻がある日を漏れ候補とし、出欠不明の日は要確認として区別する。
- 1日ずつ実時刻と理由を入力して保存。職員・操作日時・変更前後を履歴に残す。
- 保存は明示的なボタン操作時のみ。閉じる・Escは破棄。エラー時は入力を保持。
- 既存の時刻修正と打刻取消も試用できる。料金転送済みの日は閲覧のみ。
- 出欠・保護者連絡・お迎え予定・予定者・補食確認・実際のお迎え・延長分数／料金／状態を参照可能。
- 既存の取消選択肢と理由を維持。全取消ではお迎え予定・補食等も取り消す。
- 予定の変更など別機能の操作はこのモックの対象外。料金は計算せず再計算待ちとする。

