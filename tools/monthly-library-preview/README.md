## こちらの解釈・モックの仕様案

- 現行の「月案を文例から作成」を拡張。年齢・月の一致を前提に、カテゴリと検索語で候補を絞る。
- カテゴリは仮に現行の月案10セクション。元資料の見出しとの対応は取込調査後に決める。
- 年齢・月を選ぶと候補が表示される。カテゴリは「すべて」も可能。
- 「過去の原文」「AIの提案」を切替。両方から選択可能。AIには参考原文とその出典を表示する。
- カテゴリ・検索語の変更やモード切替で選択を保持。年齢・月を変える場合は確認後に選択とAI提案を解除し、基本情報は保持する。
- 対象月は検索月を初期値にする。対象月との不一致は下書き作成前に確認でき、修正が必要。
- 基本情報（対象月・クラス・作成者）、本文10項目、確認が必要な入力、各項目の編集メモ・確認済み、修正時のタイトルを省略しない。
- 「選んだ文例で作成して修正へ」でタブ内の下書きを作成。本文を修正しても選択時の原文・出典を保持。「修正を保存」でタブ内の保存見本を表示する。
- 「修正を取り消して戻る」は未保存の変更を破棄し、候補の選択または保存済み見本に戻る。選択解除は候補を除く操作。元資料を変更しない。
- 未入力・一部入力・入力済み・エラー・候補なしを上部で切替。エラー時も基本情報と選択を保持し、再試行できる。
- AIの文章は固定の動作見本。入力文脈に応じた生成や意味検索は未実装。原文サンプルも全て架空で、実ファイル由来ではない。
