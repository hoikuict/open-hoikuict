# Windowsサーバー導入アプリの操作モック

既存配布版 `beta_setup/ui/` を基準に、このPCでの試用 → 園内LAN → 園外公開を試すための独立モック。製品・OS設定・本番DBへの接続はない。

```powershell
C:\Python313\python.exe C:\python\open-hoikuict\tools\windows-server-setup-preview\serve.py
```

URL：`http://127.0.0.1:18849/`

- 上部「試す状態」で新規・未入力・一部入力・導入済み・LAN利用中・園外利用中を切り替える。
- 新規からは「このPCに導入する」→管理者→確認→準備→ホーム→LAN設定。LAN設定だけを試す場合は「このPCへの導入済み」へ切り替える。
- LAN設定ではPC確認、固定IP／園内DNSの確認、URL・HTTPS確認、メール送信と受信確認、バックアップ先確認を経て適用する。
- 「園内専用の証明書」を選ぶと、ドメイン情報の代わりに園内ホスト名と端末への証明書登録が表示される。
- LANの最終確認では別端末・再起動・復元演習を確認する。園外設定はLAN確認完了後に進める。
- 園外設定後は携帯回線・メールリンク・閲覧範囲を確認する。公開停止の取消／確定を試せる。
- エラーを解消するには「試すエラー」を「エラーなし」に戻し、再試行する。
- 入力はページのメモリー内だけ。ページを閉じる・再読み込み・試す状態の切替でリセットされる。
- 架空のドメイン・IP・トークン・結果を使用。実際のパスワードや秘密情報は入力しない。

画面・保存・取消・実装範囲の提案：`docs/windows-server-installer-proposal-2026-09-23.md`。
