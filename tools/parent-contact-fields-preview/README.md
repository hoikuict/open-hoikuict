# 保護者の連絡項目を施設・年齢・クラスで選ぶモック r2

入口：`http://127.0.0.1:8117/`。`index.html` は単体でも動く。

本番DB・アプリ・通知には接続しない。見本の2施設・0〜5歳・4クラス（混合を含む）を比較する。r2は施設ごとに年齢方式／クラス方式の一つを選び、表示する／表示しないの二択で設定する。方式の切替・年齢の区切り・固定項目・既存記録の扱いは試用提案。合意状態は `docs/spec-decisions.md` のSD-057、詳しい操作と未確定事項は `docs/parent-contact-fields-preview-2026-11-16.md`。

配備記録の基準版 `4f50cb732a21f4453fcec11f757fae79b1dd6c10` の日次連絡テンプレート・食事・睡眠・排便・検温・お迎え・園児別緊急連絡先を使用。58入力要素を保持。職員の受け取りと履歴は今回の表示確認用。新しい設定画面と業務入力画面は区別する。

「園の設定」で年齢ごと／クラスごとを選び、各列の表示／非表示を選択して仮保存する。クラス方式では混合クラス内も同じ項目。両方式の入力を別々に保持し、仮保存した方式だけを使う。切替自体は未保存。「保存前の表示を確認」は設定を保存せず見た目を確認するため、日次連絡の保存を止める。既存記録がある場合は保存時の項目を保持するため、新しい日付で新設定を確認する。

上部の詳細で未入力・入力済み・一部入力・エラーを切り替える。見本の入れ直しは選択中園児・日の仮記録を置換する。通常のタブ・施設・クラス・年齢・日付の切替は各入力を保持する。保存は同じタブのsessionStorageだけ。

```powershell
venv/Scripts/python.exe tools/parent-contact-fields-preview/build.py
node tools/parent-contact-fields-preview/verify.cjs
python -m http.server 8117 --bind 127.0.0.1 --directory tools/parent-contact-fields-preview
```

`verify.cjs` はローカルファイルを隔離ブラウザーで開き、外部通信を禁止して操作を検証。`baseline.json` に原本と生成HTMLのハッシュ、`browser-verification-r2.json` に55確認の結果を記録。`verified-r2-*.png` は架空データの確認画像。r1のHTMLと基準・検証結果は `r1/` に保存し、版名なしの以前の画像も残す。r1のブラウザー内の仮記録・下書きは保持し、設定だけr2の見本で開始する。元のr1の保存領域を削除・上書きしない。
