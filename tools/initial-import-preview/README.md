# 初期台帳Excelの確認用モック

園児1人1行、同じ行に保護者①②を入力する初期台帳フォーマットの試用。
園児整理番号・家庭整理番号・家庭名は自動設定。Excelは入力38列で、きょうだいグループのみ任意指定する仮案。
DB・アカウント・通知処理には接続しない。ブラウザー内のメモリーだけで動作する。

`index.html`をChrome/Edgeで開く。Excelダウンロードには、生成した`初期台帳_テンプレート.xlsx`を同じフォルダーへ置く。
配布用フォルダーとテンプレートは`.local-dev/initial-import-20260922/outputs/b4ed/`へ生成した。

仕様の区分・未確定事項は`docs/initial-ledger-import-proposal-2026-09-22.md`を参照。
モックは未入力・入力済み・一部入力・エラー、編集、確認、取消、架空の登録、同一内容の再読込を試せる。変更済みExcelの再取り込みと既存台帳の照合は本実装前に別途設計する。
既存のCSV入出力画面でこのExcelを取り込む機能はまだ実装していない。

共通の項目定義・検証は`core.js`。`xlsx-reader.js`はブラウザー内で.xlsxの値を読み、数式を実行せず拒否する。
実データでの移行は別途準備中。配信テスト用の98人への明示的な紐づけも、このテンプレートでは扱わない。
