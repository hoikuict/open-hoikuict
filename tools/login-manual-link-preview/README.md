# ログイン前トップからマニュアルを開く画面案

`LOGIN-MANUAL-LINK-MOCK-001`。対応する決定記録は [SD-013](../../docs/spec-decisions.md#sd-013)。

- 要望：ユーザーが添付した時計・ログイン案内のトップ画面に、マニュアルへのリンクを追加する。
- 提案：ログイン前の `portal/login_prompt.html` で「ログインする」の下に「使い方マニュアル ↗」を表示し、公開中の `https://open.hoikuict.net/manual-guide-preview/` を別タブで開く。別タブで開くことを画面上に明記する。
- 表示条件：このログイン案内画面が表示されるとき。ログイン後の個人ポータルへの追加は今回の対象に含めない。
- 保存・修正・取消：閲覧用リンクだけで、保存や業務データの更新はない。別タブを閉じれば元のログイン案内へ戻れる。
- 既存要素：サービス名、時計、ログイン案内と既存ログイン遷移を候補テンプレートに保持。入力欄がないため、未入力・部分入力・入力エラー等の状態切替は該当しない。
- 確認用画面：`dist/index.html`。確認用ラベルとログイン停止はモックだけの表示・動作。マニュアルリンクは公開ページへ実際に移動する。本番DB・メール・打刻・ログイン処理には接続しない。
- 実装候補：`candidate-login_prompt.html`。保存済み配備ソースと共有ルートの一致を確認して作成。候補を本体テンプレートへ適用したものではない。モック確認後に実装し、実機反映時は最新配備との差を再照合する。
- 未確定：配置・文言・別タブ動作に対するユーザーの確認。実装・実機配備は未実施。

```powershell

python -m http.server 8053 --bind 127.0.0.1 --directory tools/login-manual-link-preview/dist
```
