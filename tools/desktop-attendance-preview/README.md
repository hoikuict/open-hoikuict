# デスクトップの出欠確認・配置比較モック

ユーザーの要望は、デスクトップの出欠確認で園児名から目視確認ボタンまでの空白を減らすこと。
本番 `d7df60d658f3d066783c537cd5c26866911d4722` のコード・テンプレート・静的ファイルを読み込み、
独立した試用用スタイルだけを追加している。本番のファイルは変更しない。
ユーザーは「1列のまま項目を詰めて、名前とボタンを近づける」を選択した。

## 試す

<http://127.0.0.1:8888/attendance-checks/>

```powershell
venv/Scripts/python.exe -X utf8 tools/desktop-attendance-preview/server.py
```

- 「1列でコンパクト」：一覧の最大幅を1,000pxとし、名前から確認ボタンまでの距離を短くする。
- 「現在の配置」：現行の横幅で比較できる。
- 狭い画面は1列。名前・状態・打刻・保護者連絡・目視確認4ボタン・詳細は維持する。
- 日付、表示形態、絞り込み、クラス、詳細内の連絡受付・取消や履歴も本番の項目を利用する。
- 未入力／入力済み／一部入力を切り替えられる。入力状態を切り替えると架空の目視確認データを初期化する。
- 「目視確認の保存エラー（1回）」をオンにすると次の目視確認保存だけ失敗する。入力を保持し、次の保存は成功する。

## 隔離

ループバックの8888番だけで提供。架空100人のインメモリーSQLiteを使い、本番DBには接続しない。
メモリーDBへの依存関係の差し替えを維持し、通知処理は無効化。メール送信もcapture設定。
アプリの既存Tailwind・HTMXのCDN参照以外に外部との業務通信はない。
サーバー停止で試用データは消える。共有端末や本番サーバーへ配備するコードではない。
