# 第2回・職員ホームと児童票の確認版

SD-071に基づき、職員ホーム・要確認一覧・児童票作成状況・入力・レビュー依頼の5本を再照合した。`review/` は利用者確認用で、HP公開対象の `docs/` の外に置く。第1回への了承を第2回の公開承認とは扱わない。

- `build_capture.py`・`build_progress_capture.py` は保存済み配備版のテンプレートを架空データで描画する。
- `build_entry_review_capture.py` は同じ版のテスト用メモリDBを使い、保存・依頼・取り下げ・差戻し・宛先なしを照合して画面を保存する。本番DB・通知送信に接続しない。
- `capture_home.cjs`・`capture_entry_review.cjs` で全38枚を撮影する。通信をローカル資産に置き換える。後者の通信失敗・保存前移動の確認は、ブラウザーの制御とルートを置き換えた検証である。
- `finish_review.py` で画像寸法・説明・ローカルリンクを照合する。全入力欄と参考記録が入る未入力・保存後・エラーの画面も用意した。
- `review/` をlocalhost:8166で配信し、`verify.cjs` でPC・スマートフォン幅、補足、文字拡大、画像拡大を検証する。

`baseline.py` で配備記録との一致を確認する。基準ファイル26件・表示検証・画像の確認記録は `.local-dev/manual-batch2-20261123/`。実機稼働版を再取得した記録ではない。画像内の日付・氏名は説明用の例。

## 第2回の公開依頼

2026-11-23、確認版提示後の「公開して」に基づき、5本を `docs/manual-guide-preview/staff-records-20261123/` に追加した。`review/` は確認時点の本文・画像を保持する。公開URLを `verify.cjs` に渡すと公開版を検査し、共通ガイドのindex.htmlのURLを `verify_entrances.cjs` に渡すと目次・検索を検査する。配信と公開先照合の結果はSD-071に追記する。
