## 要望と提案

利用者の要望は、添付された健康管理一覧の「中心に空白が多く一覧性が損なわれている」状態の改善。列削除や項目の統合は指定されていない。

提案は7列を残して列幅を画面内に収め、長いアレルギー名と複数の健康フラグをセル内で折り返すこと。行の上下余白を12pxから9px、左右を16pxから12px（1100px以下は8px）へ縮め、操作リンクを幅に応じて並べる。交互の背景色を付ける。

r1の最小表幅980pxでは、アプリ内ブラウザーの847px幅で操作欄が画面外へ隠れた。利用者の指摘によりr2で最小幅を撤去した。720px以上は7列を表示し、719px以下は園児ごとに全7項目をラベル付きでまとめ、末尾に「操作」とリンクを表示する。表示情報や元の遷移先は省略せず、変更案は横スクロール不要。現行比較だけは元の横スクロールを維持する。狭い画面の配置もr2の試用後に合意済み。

## 試せる内容

- 「変更案」「現行の配置」を同じデータ・条件で切替。
- 在籍状況、アラート、クラス、検索の4項目を保持。入力→「絞り込む」で反映。「リセット」で初期条件に戻る。検索対象は名前・家庭名・クラス。画面の件数も連動。
- 未入力、入力済み、一部入力、読み込みエラーを切替。入力済みには長いアレルギー名・3個超のアレルギー・期限切れ・複数の健康フラグ・未登録・基本医療情報の回答待ちを含む。
- 健康サマリー、健診記録、条件付きの「基本医療情報の回答を確認」は元の遷移先を表示する確認ダイアログを開く。遷移先の編集フォームは今回の変更対象外で再現していない。「閉じる」かEscで戻る。
- 一覧には記録の保存操作はない。絞り込み条件はメモリー内のみで、再読込時に初期化。DB・本番・外部通信・送信・通知は使わない。エラーはモック確認専用で本番の新仕様ではない。
