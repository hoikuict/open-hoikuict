# 帳票の記入漏れ案内・試用版 r1.2

2026-11-15作成。SD-056／`docs/form-validation-preview-2026-11-15.md` を参照。
現在は利用者の試用待ち。本実装・追加配備の完了を示すものではない。

**現在の作業は月案に限定する。** r1.2試用後、利用者の指示で一帳票ずつ確認・訂正する進め方へ変更した。月案の入力→保存→詳細・レビュー依頼→取り下げ・修正を確認し、合意した内容を実装・検証してから次へ進む。配備は個別の依頼に従う。既存の対象一覧と他帳票のモックは参考資料として保持する。他帳票を仕様合意・配備済みとは扱わない。後続の「これで実機に反映してみましょう」で月案の実装・配備が承認された。月案の最新状態は `docs/deployment-monthly-validation-2026-11-15.md`、合意はSD-056を参照。このフォルダーは引き続き本番へ接続しない試用モック。

r1.2では月案の仮保存後の文書リンク・詳細画面6件を追加し、計44画面とした。保存→承認・文書情報→レビュー依頼→取り下げ→修正を、同じタブ内に保存した架空データで試せる。証跡は `monthly-review-verification-r1-2.json`。月案も新規の担任名を保持し、空欄の検査は「担任名を消した場合」へ分離した。本文全欄は必須にしていない。

r1.1では週案の初期値を訂正した。新規はログイン中の職員名、保存済みは記録済みの作成者名を保持する配備版の動作に合わせ、通常状態で作成者を空欄にしない。「作成者を消した場合」だけを不足の検証状態として分離した。`weekly-owner-verification-r1-1.json` が今回の6年齢の確認結果。`browser-verification.json` と従来のスクリーンショットはr1時点の過去の記録である。

## 開く

リポジトリ直下で `venv/Scripts/python.exe -m http.server 8097 --bind 127.0.0.1 --directory tools/form-validation-preview` を起動し、`http://127.0.0.1:8097/` を開く。
この端末だけで利用する静的な確認画面。月案のページ間の試用はこのローカルサーバー経由で行う。

44画面に未入力・一部入力・入力済み・保存エラーの切替がある。月案詳細では状態切替で本文を書き換えず、送信エラーを試せる。
対象一覧から帳票を選び、操作ボタンを押し、理由のリンクから修正して再操作する。
「試す操作」から、下部や折り畳み内のボタンへ移動できる。

## 基準と再生成

基準は11月15日07:11 JST配備版 `8f7bf89d9860300980a4cef781b0561ff845375c`。
`build.py` は `.local-dev/document-search-rollout-20261108/source` のコミットと差分なしを検査し、元テンプレートを架空のテストデータとメモリーDBで描画する。本番DBや原本サービスへ接続しない。
年案は既存の架空データモックから帳票の形状を引き継ぐ。元ソースと架空データのハッシュ、静的入力欄の一覧を `baseline.json` に保存する。

再生成: `venv/Scripts/python.exe tools/form-validation-preview/build.py`
静的検証: `venv/Scripts/python.exe tools/form-validation-preview/verify.py`
ブラウザー操作の結果は `browser-verification.json`、静的入力欄・接続禁止設定の検査は `static-verification.json`。再生成した際は記録済み検証結果と同じ版とは限らないため、ハッシュと必要な検証を更新する。

## 試用範囲と限界

- PV-02〜07、FV-01〜05。年案・月案・週案は0〜5歳の様式を用意する。日案作成は配備済み。お知らせ・職員アンケートは対象外。
- 現行の入力項目と必須条件を基準に、理由の位置・欄への移動・修正後の更新・入力保持を試す。年案反省は選択期のどちらかの欄に記入があれば承認確認へ進める。旧年案・旧月案の空欄を新たに必須にしない。
- 本番の保存、提出、通知、ファイル取込、競合制御、権限判定、自動保存の通信は実行しない。確認用の保存結果・通信エラー・ページを戻る案内は本実装にそのまま追加する仕様ではない。
- 月案の保存内容は同じタブのセッション内で保持する。入力画面で別の見本状態を選ぶと、その年齢の保存した見本をリセットする。その他の画面は再読み込みでリセットされる。文例は架空の例、過去3か月は空の見本。別期間の帳票生成やAI提案は今回の試用対象外。
- 議事録のマーキング・コメント・昇格フォームは全項目を保持。議事録本文は同じ位置に簡易入力欄を置いた見本で、書式・写真・共同編集は再現しない。本文保存の既存の近接ステータスは維持対象。
- 添付は見本ファイルを選ぶだけ。実装時には、サーバー再表示・再選択・サイズや種類の検査を別途確認する。
- 外部通信はCSPの `connect-src 'none'`、ネイティブ送信は `form-action 'none'` で禁止。年案・月案・週案のレンダラーへの応答はページ内の架空JSONで代替する。

このモックはサーバーの全検査を代替するものではない。試用合意後、実際のルーター・JS・JavaScriptなしの再表示、権限・競合・添付の扱いを含めて実装と検証を行う。
